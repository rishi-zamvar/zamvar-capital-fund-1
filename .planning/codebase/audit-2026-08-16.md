# Fund 1 — Codebase Audit (2026-08-16)

Read-only audit of the entire `catalyst_trader` codebase for bloat, over-engineering,
inefficiency, dead code, duplication, and structural drift. **No code was modified.**
Audited against CLAUDE.md's stated discipline: TDD, minimal deps, "simplest codebase that
works — readable end-to-end", provenance/cite-or-drop, degrade-never-crash, no-LLM-arithmetic.

Scope: `src/catalyst_trader/` (10,683 LOC), `tests/` (78 files, 1097 passing), `scripts/`,
`monitor/`, `launchd/`, `data/`, `pyproject.toml`.

---

## Executive summary — health verdict

**Overall: healthy and disciplined. This is a well-built codebase, not a bloated one.**
The stated principles are visibly honored: provenance-attached providers, degrade-to-None
isolation, `extra="forbid"` contracts, a single provider registry seam, tests-first with a
clean suite (only ONE red test, one optional skip). Dead code is minimal. There is very
little speculative abstraction. The problems are the normal residue of ~15 phases by many
agents: **(a) a couple of real backtest-scale inefficiencies that turn the backtest quadratic
as the universe grows, (b) one genuine crash-on-bad-response bug on the daily catalyst path,
(c) undeclared dependencies that would break a fresh install, and (d) two overlapping daemon
pipelines that have drifted apart.**

None of these are structural rot. All are surgical, tested fixes.

### Top 5 things to cut / fix (by impact)

1. **Fix the `fmp.py:66` crash** (P0) — a dict-shaped FMP error/rate-limit response crashes the
   *entire daily refresh* (not just the FMP slot), because `calendar/refresh.py` catches only
   `RuntimeError`. Violates degrade-never-crash. This is the known-red test.
2. **Kill the O(U²) cohort recomputation** in `quant/weekly.py` (P0) — the single biggest
   backtest-scale cost; recomputes a near-identical universe cohort U times per week.
3. **Index `catalyst_source(catalyst_id)` + stop N+1 hydration** (P0) — every verified-catalyst
   read fires one unindexed subquery per catalyst, ~2U+1 times per backtest week, hydrating
   sources three callers don't even use.
4. **Declare the 4 undeclared deps** (P1) — `beautifulsoup4`, `lxml`, `yfinance`, `pandas` are
   imported in `src/` but absent from `pyproject.toml`; a clean `pip install .` breaks at
   `registry` (bs4) and `prices` (yfinance) import.
5. **Delete `providers/base.py`** (P2, safe) — a one-implementation Protocol + type alias
   imported nowhere; the invariant it documents is already enforced at the `Catalyst` model.
   Plus **collapse the 7 copies of `_now()`** into `dates.now_iso()`.

## Efficiency list (backtest-scale)

Ordered by how badly it bites as the universe/window grows:

1. **O(U²) cohort recomputation** — `quant/weekly.py:231-245` (`_cohort_events`), called per-name via
   `weekly.py:359`. Cache the full-universe trigger pool once per `(as_of,trigger)`. **[P0, biggest]**
2. **N+1 + missing index on catalyst reads** — `store.py:130,166-171`; add
   `idx_catalyst_source_cat`, give news/hold-window/event-set callers a lightweight query, load
   once/week. **[P0]**
3. **Double base-rate compute per leg** — `backtest/engine.py:136-150` (`_base_rate_ev`) repeats what
   `_base_rate_direction` already computed. **[P1]**
4. **Hoist + cheapen `build_event_set`** — `events.py:79,88`: hoist `tradeable_catalysts` out of the
   week loop; use `SELECT 1 ... LIMIT 1` for the bars-exist check. **[P1]**
5. **Lazy heavy imports** — `pairs.py:18-19` (statsmodels), `prices.py:20-21` (pandas/yfinance) at
   module top drag the whole backtest import chain; move into the functions that use them. **[P1/P2]**
6. **Rolling-median recompute** — `weekly.py:221` (`_turnover_flag`). **[P2]**

Fixes #1 and #2 alone are what keep the backtest linear as the universe expands.

## Deliberate patterns — LEAVE ALONE (so cleanup doesn't break intent)

- **`desk/diligence.py` mirrors `desk/analysts.py`** — intentional firewall isolation (independent DD
  framework). NOT duplication; do not factor.
- **Per-provider `try/except → return []` / degrade-to-None** — intentional per-source isolation
  (degrade-never-crash). Bodies differ per source; `ingest._safe` already covers the caller side.
- **`@functools.cache` on the registry's per-ticker datum providers** (`registry.py:83-97`) — correct;
  stops a degrading source being re-hit 52× per ticker per run.
- **sqlite-vec brute-force KB search** (`kb.py`) — documented as fine at this scale (no ANN needed for
  hundreds of records). Not an efficiency finding.
- **`contracts/__init__.py` `extra="forbid"` + bounded scores + required evidence_ref** — the
  anti-hallucination spine at the message boundary. Disciplined, not over-engineered (18 refs).
- **`providers/base.py` as documentation** — if the team wants the Protocol as a written contract,
  that's a defensible reason to keep a trimmed version; flagged deletable only because nothing imports it.
- **`config.py`** — minimal, env-first, `extra="ignore"`. Exemplary; leave it.
