<objective>
Define the six pydantic v2 contracts that are the enforceable boundaries between every agent layer, with strict rejection of malformed payloads. These are the anti-hallucination spine at the message boundary: an LLM that hallucinates an extra key, omits a citation, or emits an out-of-range score is rejected by `model_validate`, not trusted. Field lists come verbatim from ARCHITECTURE.md's Pipeline-1/2 contract shapes; the validation discipline (`extra="forbid"`, evidence-ref-required) mirrors Phase-1's `_at_least_one_source`.

Purpose: KB-02's citation-or-reject invariant is enforced at two boundaries — this plan owns the CONTRACT boundary (every `key_finding` must carry a non-empty `evidence_ref`); Plan 02-03 owns the DB-write boundary (every claim node must carry a `:CITES` edge). Both are the same "no uncited claim" rule at different trust boundaries. Every later phase (analysts, debate, trade builder, risk, PM, diligence) imports these contracts.
Output: `contracts/__init__.py` with all six models + `KeyFinding`, backed by a good/bad-payload test suite.
</objective>
