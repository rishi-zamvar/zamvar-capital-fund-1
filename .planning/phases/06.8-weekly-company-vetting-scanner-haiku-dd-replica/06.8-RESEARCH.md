**What:** Migration 006 is `005_price_bars.sql` with the columns replaced by one JSON `card` column. `write_card` is the idempotent UPSERT (`store.py:185`); `card_asof` is `bars_asof` (`store.py:223`) — the `week_end <= as_of` guard is the no-look-ahead money invariant, so a backtest of the scanner never sees a future card.

  ticker TEXT NOT NULL,

### Pattern 3: `delta_card(prev, cur, params)` — pure, transition-not-level, latching + hysteresis
**What:** A pure function (no conn, no LLM, no network) returning the tripped flags. Each flag is a band/sign/set TRANSITION off the un-latched state; noise is oscillation inside a band or a re-touch of a latched flag. Latching: a fired flag records `fired[flag]=week_end` in the NEW card and cannot re-fire while the condition persists. Hysteresis: re-arm only after the metric retreats past `hysteresis_rearm_frac` of the threshold distance. Corroboration: F7/F10/F11 (CORROBORATOR) never wake Stage 2 alone. Because `delta_card` is pure over two stored cards it replays byte-identically (SCAN-02 reproducibility).
**When to use:** the Stage-1 wake gate. Its output decides who gets a Haiku pass — the "LLM cannot touch the trigger" architecture, exactly `synthesize_verdict`'s deterministic-decision role, DO-NOT-COPY the code, COPY the principle.

### Pattern 4: The ONE Haiku pass — `run_dimension` collapsed
**What:** `build_dimension_prompt` (`diligence.py:108`) assembles a prompt from ONLY firewall-input fields + a shared HARD-RULES block ("CALL the tool, never compute"; "cite-or-drop"; "fill unknowns"; "emit the exact schema"). `SCAN_PROMPT` mirrors that shape but is ONE prompt with the three scanner questions (what is of interest / is it a real explorable opportunity / what to build) and the adversarial "assume noise / already priced in / untradeable — defeat that" framing. ONE call:
```python

**Cite-or-drop:** after the call, drop any `key_finding` whose `evidence_ref` fails `evidence.resolve(conn, ref)` — structural stage only, in Python, before persist/route. DO-NOT-COPY the opus `enforce_dossier` semantic stage (SCAN-04's downstream verification is the stronger check).

### Pattern 5: Firewall as a type (mirror DiligenceInput)
`ScanInput(BaseModel, extra="forbid")` carries ONLY `{ticker, week_end, card_prev, card_cur, tripped: list[dict]}`. ## Common Pitfalls

### Pitfall 1: A rich flag object fed into `logged_flags`
**What goes wrong:** `ReconciliationRound.logged_flags` is typed `list[WeeklyFlag]` with `extra="forbid"`; a rich OpportunityFlag would fail validation or lose fields.
**How to avoid:** Route the WeeklyFlag projection only. Persist the rich object in `scan_flag`.
**Warning sign:** any import of OpportunityFlag inside md.py.

### Pitfall 2: Recomputing quant numbers in the card
**What goes wrong:** duplicating `weekly_base_rate`/`classify_drop`/turnover in `build_card` → two sources of one number, drift, and a broken F12/F13 transition test.
**How to avoid:** `build_card` receives the `thesis_scan` rows (from the run_weekly pass) and embeds the row + its tool ref verbatim. Test-pin: `weekly_base_rate` monkeypatched-to-raise during `build_card`.

### Pitfall 3: Latching without hysteresis (whipsaw)
**What goes wrong:** a metric hovering at the threshold fires every week.
**How to avoid:** re-arm only after retreat past `hysteresis_rearm_frac` of the threshold distance; a standing condition fires once (records `fired[flag]`).
**Warning sign:** the SI-at-25%-two-weeks test fires twice.

### Pitfall 4: Feed-cadence dishonesty
**What goes wrong:** treating an SI "delta" as weekly when FINRA settles bi-monthly (+~9bd lag).
**How to avoid:** F6 fires only on a NEW `si_settlement_date`; store the date on the card so staleness is visible. Same for F8 (quarterly runway).

### Pitfall 5: Corroborator waking Stage 2 alone
**What goes wrong:** F7/F10/F11 solo triggers a (cheap but noisy) Haiku pass → MD spam.
**How to avoid:** wake iff (any PRINCIPAL) OR (≥2 CORROBORATORs). Test-pin: F11 solo → `run_structured` never called.

async def run_scan(conn, embed, week_end, raw_by_ticker, thesis_rows, *, params=SCAN_PARAMS):
    srv = {"quant": build_quant_server(conn)}
    wakes = 0
    for ticker, raw in raw_by_ticker.items():
        prev = card_asof(conn, ticker, _prior_week(week_end))
        cur = build_card(conn, ticker, week_end, raw, thesis_rows[ticker], params)  # pure det.
        write_card(conn, ticker, week_end, cur)                                     # write-once
        tripped = delta_card(prev, cur, params)                                     # pure
        if not _wakes(tripped, params) or wakes >= params["scan"]["max_stage2_wakes"]:
            write_scan_flag(conn, ticker, week_end, _no_material_change(tripped))   # stored, not routed
            continue
        wakes += 1
        ctx = _analog_context(tripped, cur)          # PYTHON builds the string, not the LLM
        op = await run_structured(build_scan_prompt(ScanInput(...), ctx), OpportunityFlag,
                                  mcp_servers=srv, allowed_tools=diligence.ALLOWED_TOOLS,
                                  model="haiku")
        op = _cite_or_drop(conn, op)                 # evidence.resolve each key_finding
        write_scan_flag(conn, ticker, week_end, op, routed=(op.opportunity_type != "no_opportunity"))
    # caller passes the projected WeeklyFlags into reconcile(item={"incoming_flags": [...]})
```
