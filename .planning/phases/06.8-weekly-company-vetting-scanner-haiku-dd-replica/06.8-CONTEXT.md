# Phase 6.8: Weekly Company-Vetting Scanner (Haiku DD-Replica) - Context

**Gathered:** 2026-08-15
**Status:** Ready for planning
**Mode:** Operator architecture (2026-08-15) + research-backed (`.planning/research/weekly-company-scanner.md`)

<domain>
## Phase Boundary

A cheap, refreshable weekly scan of every universe COMPANY — a Haiku replica of the diligence workflow, but vetting the company FORWARD for the week (not a trade) to surface volatility/trading opportunities. Two stages: deterministic flaggers (from data we have) detect real week-over-week changes → only flagged names get a Haiku analyst once-over with full KB/playbook access. Emits opportunity flags UP to the MD router (Phase 6.7). Stops at the opportunity flag — the MD routes to verification; verified assumptions are added to the weekly portfolio (run_weekly); positions monitored intra-week (8.5).
</domain>

<decisions>
## Implementation Decisions (LOCKED — operator + research)

### 1. Two-stage, cheap-first (SCAN-01/03)
STAGE 1 = deterministic flaggers from data we ACTUALLY have (research enumerated 13: F1–F13), each a computable week-over-week delta vs a persisted company card with a materiality threshold + PRINCIPAL/CORROBORATOR tier. Sources: curated catalyst table + CT.gov v2 diff (catalyst-window crossings), disease-competitor-pairs map (competitor-catalyst proximity), CBOE free JSON (iv30/straddle-move/term-kink), FINRA (short-interest/days-to-cover, staleness stored honestly), `store.bars_asof` (vol-regime, MA-cross, volume-anomaly), FMP `cash_runway` + EDGAR (runway-band drop, offering filings), `quant/weekly.thesis_scan` (thesis-row transitions — consumed, never recomputed). Desirable-but-unavailable flags (analyst ratings, daily SI, 13F) marked FUTURE, not invented. STAGE 2 fires ONLY on a name that crosses the bar (monitor-by-exception — most names most weeks = a cheap "no material change" row).

### 2. Haiku analyst once-over WITH KB/playbook access (SCAN-01, Stage 2)
ONE KB-armed Haiku once-over per flagged name (NOT an 8-agent fan-out): a typed `ScanInput` firewall (card pair + tripped flags only), MANDATORY `kb.analog_query` (similar past situations + outcomes) with a Python-built deterministic context string + `kb.query_playbooks` (keyed by scenario type — playbook-vocabulary gap for non-catalyst types flagged honestly), re-cite-via-tool discipline (cite-or-drop). Output = a full `OpportunityFlag` contract with `thesis_to_verify` + `verification_needed` (gap-not-answer), and `no_opportunity` as a first-class stored outcome. Replicates the DD workflow's adversarial + cite-or-drop discipline on Haiku; agents interpret, deterministic tools compute.

### 3. Refreshable week-over-week (SCAN-02)
Write-once `company_card` table (migration 006, mirroring the `price_bar` pattern from 6.5). Pure `delta(prev, cur)`. TRANSITION-not-level semantics with latching/hysteresis reused from the intra-week anti-whipsaw research — noise vs real change decided STRUCTURALLY, replayable byte-identically. The card holds the proper volatility/opportunity metrics (IV/expected-move, short interest, days-to-catalyst, price vs MA, volume trend, cash runway, filing deltas).

### 4. Light / low-token (SCAN-03)
$0 LLM baseline (deterministic layer); ~$0.05 typical week, ~$0.21 pathological all-20 week (Haiku $1/$5 per MTok, verified pricing). Composes with (does NOT duplicate) `quant/weekly.py`. Escalate beyond Haiku only on genuine ambiguity.

### 5. Routing (SCAN-04)
OpportunityFlag → MD (Phase 6.7 `reconcile` / RECON-08 general flag router) → named VERIFICATION workflow (catalyst call / measured edge / mini-backtest — NEVER trusted un-verified) → `run_weekly` shortlist ONLY via existing catalyst/four-gate paths (NO code path from flag to Candidate — test-pinned) → Phase 8.5 monitor. The OpportunityFlag reuses the WeeklyFlag contract shape from 6.7 (gap-not-answer, extra="forbid").

### 6. Reuse discipline (research verdict)
NEW (~300-line `desk/company_scan.py` + a `company_card` migration/store + the deterministic flaggers + the ScanInput/OpportunityFlag contract if not covered by 6.7's WeeklyFlag). REUSE: `run_structured`, `build_quant_server`, `KeyFinding`, `evidence.resolve`, `options_liquid`, `store.bars_asof`, `quant/weekly.thesis_scan`, `kb.analog_query`/`query_playbooks`, the WeeklyFlag contract (6.7). DO-NOT-COPY: the 8-dim fan-out, `synthesize_verdict`, and the opus `enforce_dossier` stage (this is ONE Haiku pass, not the full DD machinery). Fully offline (synthetic cards + monkeypatched run_structured). Full TDD (`.venv/bin/python -m pytest`, bare python NOT on PATH). Graphify graph-first (2478 nodes, fresh).
</decisions>
