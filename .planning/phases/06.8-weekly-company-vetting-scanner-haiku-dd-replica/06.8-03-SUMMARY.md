# Phase 06.8 Plan 03: Stage-2 Haiku Scanner + MD Routing Summary

Stage-2 and the closed routing loop: the adversarial `SCAN_PROMPT` (DD HARD-RULES + the three company-forward questions as ONE consolidated pass), the `run_scan` orchestrator (wake gate -> one Haiku pass per woken name over the reused quant/KB tool surface -> structural cite-or-drop -> persist + route), and the pure `to_weekly_flag` projection that hands a `WeeklyFlag(flag_type="qual")` to the existing MD router — with **zero md.py change**. This is the qualitative producer of WEEK-06 flags and the SCAN-04 routing seam.

## What Was Built

**Task 1 — SCAN_PROMPT + run_scan (ONE Haiku pass, cite-or-drop).** `SCAN_PROMPT` reshapes the diligence desk's HARD-RULES discipline (CALL the `mcp__quant__*` tool never compute; cite-or-drop every key_finding; fill unknowns; emit exactly the OpportunityFlag schema) into a single company-forward pass with the adversarial "assume it's noise / priced-in / untradeable" framing and the three ordered questions (interest / explorable / verify-or-build). `build_scan_prompt` assembles from ONLY firewall `ScanInput` fields + the Python-built context; `_analog_context` is a deterministic serialization of the tripped flags (code + readable name + prev->cur + threshold) the LLM never authors. `run_scan(conn, embed, week_end, raw_by_ticker, thesis_rows, *, params)`:
- for each name: `prev = card_asof(prior_week)` -> `cur = build_card(...)` -> `tripped = delta_card(prev, cur)` (mutates `cur["fired"]`) -> **`write_card` AFTER** (the SCAN-02 latch-memory money-gate);
- `not _wakes(...)` OR `wakes >= max_stage2_wakes` -> stored `no_material_change` row (routed=False), continue;
- catalyst-precedence guard: bare-F1 on a `thesis_type=="catalyst"` name -> stored `catalyst_precedence` row, not woken;
- else ONE `await run_structured(build_scan_prompt(...), OpportunityFlag, mcp_servers={"quant": build_quant_server(conn)}, allowed_tools=diligence.ALLOWED_TOOLS, model="haiku")`, sonnet escalation on low confidence, structural `_cite_or_drop`, `write_scan_flag(routed=(type != no_opportunity))`.

**Task 2 — to_weekly_flag + MD routing (zero md.py change).** `to_weekly_flag(op)` is a PURE projection: `None` for `no_opportunity` (stored-not-routed) or nothing-citable; else `WeeklyFlag(ticker, flag_type="qual", finding=op.thesis_to_verify, evidence_ref=<promoted ref>, why_material=<factual, from opportunity_type + tripped_flags>)`. The promoted ref is the first surviving key_finding (cite-or-drop already ran, so it is the strongest resolvable) else the first kb_analog. `verification_needed` is structurally absent from `WeeklyFlag`, so it can never cross the wire; it lives only in the `scan_flag` audit payload (`op.model_dump()`). The projected flag rides the existing `reconcile` `item["incoming_flags"]` seam into round-1 `logged_flags` with `md.py` untouched.
