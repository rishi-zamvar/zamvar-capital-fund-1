# Phase 06.11 Plan 02: Wire pdufa_edgar onto the Daemon Path Summary

Registered `pdufa_edgar` as a first-class daemon-path provider slot (registry + CADENCE + `ingest._fetch_catalysts`) so our own SEC-EDGAR PDUFA discovery auto-populates every `daemon.run_cycle` — closing the wiring gap the pdufa debug exposed (the curated loader was only reachable via `refresh.py main()`, never on `run_cycle`) — and proved end-to-end that a single `"SEC EDGAR"` primary Catalyst self-verifies to `Status.verified`, becomes tradeable, and is point-in-time stamped from the 8-K filing_date through the REAL insert->verify->`_pit_stamp` pipeline, with zero `verify.py` change.

## What Was Built

**Task 1 — daemon-path wiring (registry + CADENCE + ingest):**
- `registry.build_providers`: added `pdufa_edgar` to the provider import block and a `"pdufa_edgar"` slot lambda mirroring the `pdufa` slot exactly (`tks, s, e, company_map` passthrough to `pdufa_edgar.fetch`).
- `registry.CADENCE["pdufa_edgar"] = _DAY` — catalysts refresh daily.
- `ingest._fetch_catalysts`: appended `_safe(providers.get("pdufa_edgar"), tickers, start, end, company_map=company_map) or []` — so it runs on the daemon path (`daemon.run_cycle -> ingest.ingest_history -> _fetch_catalysts`) and degrades to `[]` when the slot is absent/raises.
- The existing `pdufa` slot and `pdufa.py` are untouched (optional discovery redundancy).

**Task 2 — verify-synergy integration test (`tests/test_ingest_seam.py`):**
- `test_pdufa_edgar_single_source_verifies_and_stamps`: a fake `pdufa_edgar` slot returns one `"SEC EDGAR"` primary Catalyst (`published_date` = 8-K filing_date `2026-08-11`), run through the REAL `ingest_history` -> `_fetch_catalysts` -> `insert_catalyst` -> `verify.verify_catalyst` -> `_pit_stamp` path. Asserts `status == verified`, `last_verified_at == "2026-08-11"` (the filing_date, NOT now/event_date), and that it appears in `store.tradeable_catalysts`.
- `test_pdufa_edgar_degrades_when_slot_missing`: a providers dict without a `pdufa_edgar` slot -> `ingest_history` runs clean (no raise), zero catalysts.
