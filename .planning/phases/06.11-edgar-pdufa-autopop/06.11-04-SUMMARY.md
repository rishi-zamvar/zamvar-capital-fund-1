## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `pit_ok` compared against the non-persisted `published_date` (script-level, pre-commit)**
- **Found during:** Task 1 (first live run)
- **Issue:** `published_date` is transport-only and never persisted (per `ingest._pit_stamp`); reading it back via `store.get_catalyst` returns None, so `pit_ok` computed False even though `last_verified_at` was correctly the filing_date.
- **Fix:** capture the 8-K filing_date from the IN-MEMORY Catalyst before insert (exactly as `_pit_stamp` reads it) and compare `last_verified_at` against that.
- **Files modified:** scripts/pdufa_edgar_live_verify.py (fixed before the task commit — no separate fix commit)

**2. [Rule 1 - Bug] review-queue count undercounted on re-run (script-level, pre-commit)**
- **Issue:** a before/after CSV diff returns 0 on the second run because the append is idempotent.
- **Fix:** report all `pdufa_edgar`-attributable (`"SEC EDGAR"`) `#`-rows present after the run — stable across re-runs.

**No `pdufa_edgar.py` change needed** — the extractor, CIK filter, confidence gate, degrade path, and point-in-time stamp all worked on live filings on the first real run.
