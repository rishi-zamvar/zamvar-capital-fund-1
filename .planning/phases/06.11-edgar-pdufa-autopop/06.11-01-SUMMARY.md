# Phase 06.11 Plan 01: providers/pdufa_edgar.py — our own PDUFA source from SEC 8-K filings Summary

Deterministic, no-LLM PDUFA/AdCom catalyst source: efts full-text discovery (CIK-filtered to the universe) → RAW-HTML 8-K exhibit fetch → HTML→text normalize (tag-strip) FIRST → keyword-adjacent-date regex → single-source `"SEC EDGAR"` primary Catalyst that self-verifies via the DATA-03 amendment with zero verify.py change.

## What was built

**Task 1 — HTML→text normalize + deterministic extraction:**
- `_normalize(html)`: `BeautifulSoup(html, "html.parser").get_text(separator=" ")` + whitespace-collapse (regex tag-strip fallback if bs4 import ever fails). Tags → spaces, so a `PDUFA target action date</span> of <span>April 28, 2027` split rejoins into `...target action date of April 28, 2027` and the ~40-char adjacency holds.
- `_extract(html, filing_date)`: normalize FIRST, then `_PDUFA_RX` + `_ADCOM_RX` over the text; dedupe the 3×-repeated date; classify HIGH vs MEDIUM. `_norm_date` (reused from pdufa.py) enforces cite-or-drop on the date.
- Fixtures are **real-HTML-shaped** 8-K EX-99.1 snippets from the live IMNM (April 28, 2027) / CAPR (August 22, 2026) filings, each with ≥1 tag-split keyword/date occurrence.

**Task 2 — efts discovery + emit + review routing:**
- `fetch(tickers, date_from, date_to, *, company_map=None)` mirrors `pdufa.fetch`'s signature (drop-in for the Plan-02 ingest slot).
- `_cik_map` resolves ticker→CIK via `edgar.Company(t).cik` (edgar.py pattern); `_discover` runs the 3 keyword-phrase efts queries and filters hits by exact `_source.ciks ∩ universe` (NO fuzzy title), deduped by accession.
- HIGH → `Catalyst` with exactly one `CatalystSource(source_name="SEC EDGAR", source_type=primary, published_date=filing_date)`, `external_ref=pdufa_edgar:{ticker}:{accession}`.
- MEDIUM/LOW → `#`-commented row appended to the injectable `_CURATED_CSV` module constant (human uncomments to confirm; idempotent).
- Degrade-not-raise on every efts/exhibit/edgartools failure.

## Confirmations (from the offline suite, 15 tests green)

- **HTML-normalize-before-regex works on tag-split fixtures:** `test_normalize_rejoins_tag_split_keyword_date` proves `_PDUFA_RX` does NOT match the raw `date</span> of <span>April 28, 2027` but DOES after `_normalize`. IMNM/CAPR .htm fixtures extract 2027-04-28 / 2026-08-22 at HIGH.
- **No bare date emits:** `test_extract_no_keyword_no_date` — a date with no adjacent keyword → `[]`. `test_extract_unparseable_date_dropped` — garbage date → dropped.
- **Single "SEC EDGAR" source self-verifies:** `test_fetch_catalyst_self_verifies` asserts `verify._authoritative_single(cat.sources) is True` against the REAL verify.py.
- **MEDIUM/LOW route as `#`-commented rows (human gate preserved):** `test_fetch_medium_routes_to_review_csv_not_emitted` — not in the returned list, one `#`-row in the tmp_path CSV, idempotent on re-run.
- **PIT stamp from filing_date:** `test_fetch_emits_single_sec_edgar_primary` asserts `published_date == "2026-08-11"` (the 8-K filing_date), distinct from event_date.
