# Phase 06.11 Plan 03: providers/robinhood.py — Robinhood MCP Data Adapter Summary

Read-only Robinhood Agentic MCP data adapter over an injectable `mcp_call(tool_name, args) -> dict` seam — quotes_rt, fundamentals(float), portfolio, historicals — degrading to None exactly like the macro/FRED gate, plus four gated registry slots and an additive float-into-cards wiring, all proven offline against the real 2026-08-16 probed shapes.

## What shipped

- **`providers/robinhood.py`** — four read-only slots over `mcp_call` (the Claude Agent SDK MCP surface, NOT `_http`); no top-level SDK/MCP import (headless-safe). Each slot returns None when `mcp_call` is None/absent or raises. Every numeric field is `float()`-coerced with a None-guard because the real probed responses are string-typed. Provenance `source_name="Robinhood"`, grade `"yellow"`.
  - `quotes_rt(tickers)` — get_equity_quotes -> `{SYM: {last, bid, ask, prev_close, official_close, close_date, provenance}}`.
  - `fundamentals(ticker)` — get_equity_fundamentals -> `{float, shares_outstanding, market_cap, high_52_weeks, low_52_weeks, provenance}` (the float-gap filler).
  - `portfolio()` — get_portfolio(560662892) -> `{total_value, equity_value, cash, buying_power, provenance}`.
  - `historicals(ticker)` — get_equity_historicals(adjustment_type="none") -> raw OHLCV bar list; a cross-check VOTE only.
- **`registry.build_providers`** — `rh_call = getattr(settings, "rh_mcp_call", None)`; four slots (`quotes_rt`, `float`, `portfolio`, `rh_historicals`) are None until bound, callable when bound (route through the adapter with the injected callable). CADENCE entries added for each.
- **`ingest.assemble_raw`** — additive `raw["float"]` (RH) and `raw["shares_outstanding"]` (RH primary, degrade to edgar `financials` shares). Additive keys only; the existing raw key set is preserved (build_card contract unchanged).
- **`config.py`** — `rh_mcp_url` env seam (`RH_MCP_URL`); the actual callable is runtime-bound as `settings.rh_mcp_call` by the SDK.
