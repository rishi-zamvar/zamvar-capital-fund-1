# Phase 07.6 Plan 02: Serving Gateway Mechanism Summary

The mandatory deny-by-default serving seam: `serving.asof(conn, cutoff)` returns a `Databook` whose accessors inject a `knowable <= cutoff` transaction-time filter on top of the shipped valid-time reads. An unregistered table or a NULL knowable stamp RAISES `LookAheadDenied` (never a silent `[]`). Ships the mechanism + `StampSpec`/`STAMP_REGISTRY` structure + the fully-wired `price_bar` accessor as the template Plan 03 replicates.

## What was built

- **serving.py**: `LookAheadDenied`, `StampSpec(valid_col, knowable_expr, data_class)`, `STAMP_REGISTRY` (price_bar seeded), `asof()` factory (cutoff=None → now_iso), `Databook` with `_require` (deny-by-default), `_effective_cutoff` (reused `fill.effective_asof`, no silent 0-lag), `bars()` accessor, `_guard_not_null` helper.
