# Phase 07.6 Plan 03: Full Stamp Registry + Accessors Summary

The `STAMP_REGISTRY` now encodes the audited knowable stamp for all 9 served tables, and every accessor is implemented. The catalyst event_date bug is fixed (resolve via `catalyst_version_asof`, never gate on the scheduled `event_date` nor on `last_verified_at`); the price_bar/company_card backfill trap is avoided (gate on `week_end`, never `retrieved_at`); scan_flag/universe gate on `recorded_at`; and a realistic per-data-class ingestion lag is wired through the reused `fill.effective_asof`.

## What was built

- **Registry (9 tables)**: price_bar, company_card (week_end); scan_flag, universe_snapshot (recorded_at); catalyst (version-resolved); catalyst_move (knowable_asof); trigger_event (fired_at); kb_node/kb_edge (created_at). Each with an inline audit comment.
- **Accessors**: `catalysts()` (bitemporal resolve, drops not-yet-knowable), `card`, `scan_flags` (two-column gate + NULL-deny), `universe` (cohort knowability + NULL-deny), `catalyst_moves`, `kb_nodes`, `kb_edges`.

- Full suite: **1227 passed** (1209 + 18), zero regressions.

## Invariants honored

- price_bar/company_card gate on week_end (+lag), NEVER retrieved_at (grep-enforced). ✅
- Deny-by-default RAISES LookAheadDenied (NULL recorded_at on scan_flag/universe). ✅
- effective_asof reused (raises on unconfigured class — no silent 0-lag). ✅
- Catalyst gated on the version's recorded_at, not event_date, not last_verified_at (nit #1). ✅

## Plan-check nit #1 (folded in)

`test_catalyst_gate_uses_recorded_at_not_last_verified_at`: a catalyst whose `last_verified_at` is set to a much later (post-cutoff) re-verification, but whose version `recorded_at` is pre-cutoff, is STILL served — asserting the gate is the version transaction time, documenting the intended gate-semantics correction.

## Deviations from Plan

None material. catalyst_move/kb NULL-denial: those columns are NOT NULL by schema, so denial is structural; the accessors still route every row through the shared `_guard_not_null` (defensive), tested directly. The genuinely-nullable stamps (scan_flag/universe recorded_at) have real end-to-end NULL-deny tests.
