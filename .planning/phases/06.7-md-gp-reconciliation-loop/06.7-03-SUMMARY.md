**`cross_check` — a pure, no-LLM diff across the catalyst verdict / portfolio dossier / diligence dossier (plus the authoritative catalyst_id and the min_tradeable_size floor threaded in) that pre-computes every inter-workflow inconsistency the MD would otherwise hunt for, and exposes a single `clean` boolean the Plan-04 bounded loop uses for convergence.**

## Accomplishments
- `desk/md.py::cross_check` — the first symbol in the new MD desk module, a pure deterministic function (imports only the four contract types; no LLM, no conn, no kb). Pre-computes six inter-workflow inconsistencies so the MD call is pure judgment and the loop gets a deterministic convergence signal.
- Six checks, each tested in isolation off a mutually-consistent baseline:
  1. `catalyst_id_consistent` — threaded id vs `dossier.trade.catalyst_id` vs each DD `per_dimension['catalyst_id']` (the §4.1 escalation-worthy factual conflict; the verdict carries no id so the threaded param is authoritative).
  2. `dd_vs_portfolio` — DD `no_go` while the portfolio `promote`s (the core reconciliation tension).
  3. `direction_consistent` — `verdict.direction` vs `dossier.trade.direction` (regression guard).
  4. `uncovered_red_flags` — DD red_flags not answered by kill_criteria / priced residuals (dissent_log) / hedge mechanism.
  5. `dd_vs_risk_residuals` — DD residuals absent from the dossier residual surface (dissent_log).
  6. `sizing_vs_survival` — the coverage/net-long/hold-through TRIPLE (`which_risk_covered=='none'` AND `size_pct > min_tradeable_size` AND `holds_through_catalyst`) — no magic number, no `RiskAssessment.ruin_at_size` (not on the dossier).
- `clean = True` iff none of the six fired — the single boolean Plan 04's convergence `and` consumes (loop control stays Python).
- 8 new tests (clean baseline + each inconsistency in isolation + covered/uncovered discrimination + below-floor edge). Full suite 776 → 784, no regression.
