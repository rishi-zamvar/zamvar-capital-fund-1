# Phase 6.12 Plan 02: Screen + Measure-and-Grow + Write Summary

Consumes Plan 01's CIK-keyed candidate set and produces a survivorship-free `universe_as_of` cohort sized by MEASURING forward catalyst density (N is an output), written via the reused `build_snapshot`.

## What was built

- **`screen_candidates`** — per-candidate ADV (`_dollar_adv`, weekly->daily /5 proxy), market-cap (`_market_cap` = shares_outstanding * latest cascade close), optionability (`_optionable`), and cash-runway reads. Admits iff ADV>=$5M (or $2-5M -> `size_tiny`), cap in [$200M,$10B] (or `hedge_peer_band` to ~$16B), optionable, cap readable. A degraded ADV/cap/optionability datum -> DROP with a reason (cite-or-drop, never imputed). Runway None is legit (not burning) -> `runway_unknown` flag, not a drop.
- **`_optionable`** — bid>0 BOTH legs AND `call_oi+put_oi>=100` AND straddle `spread/mid < 0.6` (money-path liquidity gate); None on `options_cboe.fetch` degrade. Expiry-at/after-catalyst deferred to the per-trade desk (noted in-code).
- **`_enforce_diversity`** — caps any TA cluster at `max_per_ta` (default 4), keeping the densest-catalyst names, demoting the rest with `ta_cluster_full`.
- **`size_to_density`** — ranks densest-first, grows the shortlist one at a time, stops at projected weekly lambda >= target (default 1.75, average-across-year) OR safety_cap (90) OR pool exhaustion. Earnings never counted. Returns N-as-output + a density report (measured_lambda, target_reached, per_name_rate_used, base-rate recalibration note flagged for Phase 7.5, lean_week_estimate).
- **`build_universe`** — orchestrates discover -> screen -> diversity -> size -> `build_snapshot` with `min_catalyst_density=0` (Blocker-1 fix), returns a run summary with per-name provenance, a distinct `included_count` that reconciles with `n_admitted`, and the UNIV-05 breadth/depth tradeoff note.
