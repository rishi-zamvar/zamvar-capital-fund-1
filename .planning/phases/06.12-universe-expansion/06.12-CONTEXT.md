<decisions>
## Implementation Decisions (LOCKED — from research Part A)

### 1. Candidate discovery from our own free data (no hand-picking) — UNIV-01
- CT.gov near-term Ph2/Ph3 studies with upcoming `primaryCompletionDate` → lead-sponsor → ticker (reverse of `ticker_sponsor_map`).
- Unfiltered EDGAR-8K PDUFA `efts` pass (reuse pdufa_edgar's discovery) → resolve ticker per hit.
- Output candidate tickers with their catalyst evidence.

### 2. Screen for tradeability + fit-ability — UNIV-02
- Dollar-ADV floor (~$5M tradeable; $2-5M size-tiny tier) via the price cascade.
- Optionability (listed options) via CBOE — needed for the implied-move + hedge legs.
- Market-cap floor/ceiling + cash-runway sanity via edgartools fundamentals.
- Therapeutic-area + catalyst-type DIVERSITY (so cohort-level fitting later has populated cells).

### 3. Measure-and-grow sizing — N is an OUTPUT, not hard-coded — UNIV-03
- Do NOT hard-code N=80. Grow the shortlist until store-measured trailing-catalyst density ≥ target λ (~1.75-2.0 tradeable/week). Re-measure the soft base rates (per-name catalyst rate ~2/yr, cull fraction) from the store, not the estimate — self-correcting.

### 4. Write to the shipped survivorship-free store — UNIV-04
- `universe/discover.py` → `build_snapshot` (append-only, CIK-keyed for ticker-recycling, point-in-time). Reuse the existing `universe_as_of` store; do NOT invent a new one.

### 5. Honest breadth/depth tradeoff — UNIV-05
- More names = more diligence load + less per-name eyeballing; the per-catalyst diligence + verify gates still gate every trade; the weekly desk SELECTS the best (≥1/wk = enough to choose from, not trade-all). Automated screening + provenance compensate. Surface this explicitly.

### 6. Reuse + discipline
Reuse: CT.gov provider + ticker_sponsor_map, pdufa_edgar efts discovery, price cascade (ADV), CBOE (optionability), edgartools (cap/float/runway), `universe/build.build_snapshot`, the survivorship-free store. NEW: one `universe/discover.py` (discovery + screen + measure-and-grow). Full TDD offline (mock the providers / injected fixtures — real-shape). A separate live run expands the actual universe (operator-directed, like prior shakedowns). FREE data; provenance/cite-or-drop; `.venv/bin/python`; Graphify graph-first; plan-check ON (feeds the money path). NO new dep, NO migration.
</decisions>
