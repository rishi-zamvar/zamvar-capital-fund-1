# Phase 06.12 Plan 04: options_cboe ATM-Selection Bug Fix Summary

Root-cause fix in `providers/options_cboe.py` so `fetch` selects the LIQUID, near-spot, standard-monthly ATM pair instead of the earliest expiry's nearest-to-spot bid>0 pair — closing the 06.12-03 live-close bug where VERA (spot $31.71) got a ~$0.20 deep-OTM "ATM" call from a thin near-dated weekly and 17/20 real liquid names were falsely rejected as `not_optionable`.

## What was built

- **`_atm_live_pair` now applies an OI floor + near-spot band.** A pair qualifies iff both legs have bid>0 (Pitfall 2, unchanged), combined open interest >= `MIN_ATM_OI` (25), and the strike is within `ATM_BAND` (0.15) of spot; nearest-to-spot among the qualifiers. Same signature (records-for-one-expiry, spot).
- **`fetch` now does monthly-preferred expiry selection.** It gathers every expiry with a qualifying pair, then takes the earliest STANDARD MONTHLY (3rd Friday: `weekday()==4 and 15<=day<=21`, via new `_is_monthly`), falling back to the earliest qualifying expiry only when no monthly qualifies — replacing the old "first expiry with any bid>0 pair wins" loop.
- **Contract preserved byte-for-byte.** The 7-key `options_quote` ({call_bid,call_ask,put_bid,put_ask,call_oi,put_oi,expiry}), `underlying_quote` {bid,volume,oi}, `iv30`, `term_spread`, `straddle_move_pct`, `straddle_median`, `underlying_price`, `provenance` — same keys, same complete-or-None behavior. `term_spread` reuses the fixed qualifier on a later expiry; `straddle_move_pct` still delegated to `quant.implied_move`.
- **Pitfall-2 junk-IV guard intact.** No qualifying liquid ATM anywhere → `options_quote=None` AND `iv30=None`, `underlying_quote.oi=0`. The band/OI floor make the guard *stronger* (a far-OTM-only or ghost-OI chain now correctly degrades) without weakening it.
