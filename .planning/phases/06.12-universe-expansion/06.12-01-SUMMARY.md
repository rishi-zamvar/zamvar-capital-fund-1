# Phase 6.12 Plan 01: Data-Driven Candidate Discovery Summary

Sources catalyst-dense biotech candidates from our own free feeds — CT.gov reverse-sponsor + un-filtered EDGAR-8K efts PDUFA — merged into one CIK-keyed candidate set carrying live-parity catalyst evidence (PDUFA + trial readout + AdCom only).

## What was built

- **`discover_ctgov`** — runs the shipped CT.gov provider BACKWARD: an UNFILTERED near-term interventional Ph2/Ph3 `primaryCompletionDate` query (no `query.spons`), each study's `leadSponsor.name` reverse-mapped to a ticker via the inverted `ticker_sponsor_map`. Resolved -> a CIK-keyed candidate with a `trial_readout` catalyst + provenance; unmapped -> a `#`-commented row in `_SPONSOR_REVIEW_CSV` (idempotent, cite-or-drop, never fuzzy). Ph1 studies dropped; CT.gov failure degrades to `{}`.
- **`discover_edgar`** — the shipped efts PDUFA pass with NO universe-CIK intersection (the primary new-name engine). Ticker resolved per hit from `display_names[0]` via a NON-anchored regex (take-last) that survives the real `"Name (TICKER) (CIK 0001234567)"` trailing-CIK form; CIK = `int(ciks[0])`. Only HIGH-confidence `_extract` PDUFA/AdCom extractions admitted; no-ticker / no-CIK hits dropped.
- **`discover_candidates`** — merges both feeds by CIK, unioning catalysts (a CIK in both feeds gets both a `trial_readout` and a `pdufa`, `source_feeds == {ctgov, edgar}`), filtered to live-parity types; one feed failing still returns the other.
- **`data/ticker_sponsor_map.csv`** — extended with 8 additional live-shaped legal sponsor names to raise reverse-map coverage.
