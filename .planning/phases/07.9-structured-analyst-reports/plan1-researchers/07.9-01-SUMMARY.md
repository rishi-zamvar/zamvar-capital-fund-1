# Phase 07.9 Plan 01: Researcher Structured Lens Reports Summary

The 4 catalyst-call analysts (clinical/regulatory/financial/market_sentiment) now emit
lens-specific, data-rich, plain-language one-pager reports (guideline §1-4 sections + §7
schema) instead of the thin shared `AnalystSignal`. The schema split is clean: the 8 DD
dimensions keep the unchanged `AnalystSignal` (Plan 2 migrates them) — `diligence.py`, the
`dd_*_signal` fixtures, and the generic runtime seam are provably untouched.

## The 4 lens contracts

All subclass `AnalystReportBase` (the debate/verifier interface: `dimension, ticker,
catalyst_id, thesis` [=BOTTOM LINE], `score, confidence, key_findings` [>=1 cited],
`kb_analogs_queried, unknowns` + the copied `_at_least_one_sourced_finding` validator).
Each adds guideline-§7 section sub-models (`extra="forbid"`, `frozen=True`, every numeric/
string leaf `Optional`-default-`None`; sections default-construct so an empty report is
buildable):

- **ClinicalReport** — DiseaseUnmetNeed, Moa, TrialDesign, Endpoints, Efficacy, Safety
  + `prior_consistency`, `key_scientific_risk`, headline `pos_estimate`/`pos_estimate_source`.
- **RegulatoryReport** — Application, Division, PriorCrl, AdCom, LabelRisk, Poa (with
  scenarios clean_approve/approve_restricted/crl) + `regulatory_question`, `precedent`.
  Headline `poa.point`/`poa.point_source`.
- **FinancialReport** — Liquidity, Runway, CapitalStructure, `financing_history: list[FinancingRound]`,
  Insiders, Rnpv + `signal_synthesis`. Headline `rnpv.rnpv_m`/`rnpv.rnpv_source`.
- **MarketReport** — RunUp, ExpectedMove, ImpliedProb, ShortInterest, Ownership, Sentiment,
  `analogs: list[Analog]`, Asymmetry. Headline `asymmetry.ev_pct`/`asymmetry.ev_source`.

## The no-fabrication invariant

Two enforced layers:
1. **Nullable-by-default numerics** — any number an analyst cannot source stays `None` (an
   empty slot is a finding, never a fabricated `0`).
2. **Headline paired-source** — a `@model_validator(mode="after")` on each lens raises if
   its ONE load-bearing verdict number is non-null while its paired `_source` is empty/None.
   This is the machine-enforceable slice of §7's "every number carries a paired `_source`"
   ("where enforceable" scope — the headline verdict number, not all ~30 leaves).
Plus the base spine: `thesis` min_length=1, `key_findings` >=1 cited, `score∈[-1,1]`,
`confidence∈[0,1]`, `extra="forbid"` on the report AND every nested section.

## The Plain-Language rules (build_prompt HARD RULE 7)

Added alongside the preserved cite-or-drop / grounded-thesis / depth rules (1-6, verbatim):
(a) **define** every technical term inline the first time; (b) every number **gets context**
— good/bad vs which **benchmark**, never bare; (c) **lead with the bottom line** then the
evidence; and unavailable numbers are **left null**, never fabricated. Each PROMPTS entry is
now a full one-pager template: guideline §1-4 ordered section headers + a data-point-checklist
cue + the (C) framework heuristic, persona voice preserved.
