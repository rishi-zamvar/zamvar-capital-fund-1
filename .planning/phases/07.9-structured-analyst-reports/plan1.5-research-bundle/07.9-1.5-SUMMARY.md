# Phase 07.9 Plan 1.5: Catalyst Research Bundle Summary

One deterministic research pass computes every free/cited FACT once per catalyst into a
facts-only, evidence-tagged substrate (`CatalystResearchBundle`), and `make_diligence_inputs`
(the DD data feed) now sources its `market_data` FROM that bundle instead of re-fetching — one
consumer proven, byte-compatible, firewall intact.

## The bundle contract (facts-only proof)

`contracts.Fact` — a generic cited-datum carrier: `value: Any = None`, `evidence_ref`, `citation`,
`context`, `extra='forbid'`, plus a `_cite_or_drop` model_validator (a populated value with neither a
resolvable `evidence_ref` nor an inline `citation` is a `ValidationError`).

`contracts.CatalystResearchBundle` — `extra='forbid'`; `ticker` / `catalyst` / `as_of` + the facts:
`analogs`, `base_rates: list[Fact]`, `financials`, `trial`, `options`, `implied_move`, `ownership`,
`prices`, `hedge_inputs`, and `degraded: list[str]`. Every fact defaults to an empty `Fact`
(value=None) — an unsourced slot is a finding, never a fabricated 0.

FACTS-ONLY is a TYPE invariant, not a policy pass — both proven by test:
- `test_bundle_is_facts_only_no_interpretation_fields` — `model_fields` carries NONE of
  {score, confidence, thesis, verdict, dossier, recommendation, decision, key_findings, direction}.
- `test_bundle_forbids_extra` — constructing with `score=0.7` raises `ValidationError`.

`CatalystResearchBundle.fact_for(tool_name, inputs)` returns the fact whose `evidence_ref ==
tool_ref_for(tool_name, inputs)` — shaping the bundle for the Plan-2 `build_quant_tools` cache lookup
(a one-liner later). Built but not wired to the analysts this plan (staged).

## Sources orchestrated (each once — re-implemented none)

| Fact | Source (orchestrated) | Citation |
|------|----------------------|----------|
| analogs + hedge_inputs | `kb.analog_query` (ONE call feeds both; hedge_inputs = `_split_moves` over `_NO_ANALOG_GAPS`, C4) | `tool:analog_query#…` |
| base_rates | `quant.base_rate` per distinct metric (pos/crl_penalty/adcom_followthrough; RAISES→degrade, C2-style) | inline `{source_name,source_url,quote}` |

| trial | honest `lambda t: None` default (C3 — `fetch_trial_readouts` is a plural-ticker discovery fn, NOT per-catalyst) | `tool:trial_readouts#…` when present |
| options + implied_move | `options_cboe.fetch` + `quant.implied_move` (C2: wrapped in try/except → null+flag) | `tool:options_cboe#…` / `tool:implied_move#…` |
| prices | `serving.asof(conn, cutoff).bars` — point-in-time close series | `tool:price_bars#…` |

Frugality proven by `test_computed_once`: call-count spies confirm analog/financials/options/finra/
insider/price each fire EXACTLY once; base_rate once per DISTINCT metric (never the same twice); the
single `edgar.fundamentals` fetch serves both financials and ownership shares.

Honest-degrade proven by `test_honest_degrade_missing_source` (missing financials+finra → null facts
+ flags, no fabricated number), `test_insider_zero_grounds` (0.0 quiet tape GROUNDS ownership),
point-in-time by `test_point_in_time` (+ `test_point_in_time_default_no_lookahead` through
`serving.asof`), cite-or-drop by `test_every_populated_fact_has_resolvable_ref`.

## The make_diligence_inputs delegation (no-double-sourcing + DD byte-compat)

`make_diligence_inputs` now builds the bundle ONCE (`facts={options, financials, ownership, trial}`,
`cutoff=as_of`) and maps facts → the same `market_data` dict (options+sentinel, liquidity_quote,
hedge from risk_inputs verbatim, financials + months_to_catalyst, ownership, trial). The per-source
kwargs are threaded into the bundle; `bundle_fn` is injectable for tests.

- **No-double-sourcing** — `test_no_double_sourcing`: options/financials/finra/insider each hit once
  (via the bundle), never re-fetched at the DD seam.
- **DD byte-compat (B1, acceptance gate)** — the entire pre-existing `test_desk_diligence_inputs`
  suite stays byte-green: `degraded == []` when grounded, same `md` keys, `conn=None` safe. This holds
  because the DD path requests ONLY its 4 facts, so the conn-touching sources (analog/base_rate/price)
  never fire; `degraded` is additionally scoped to `financials:`/`ownership:` flags (no-op safety net).
- `test_live_desk_decision` (the promoted-trade DD consumer) stays green — bundle production defaults
  match the old DD defaults exactly (offline → None → honest degrade flags carried forward).

## C5 — qualitative facts are OUT of the substrate (for Plan 2)

The bundle carries ONLY the DETERMINISTIC free-source facts (analogs, base_rates, financials, trial,
options, implied_move, ownership, prices, hedge_inputs). The QUALITATIVE guideline facts — rNPV,
prior-CRL narrative, AdCom outcome, MoA, label risk — are NOT in the substrate; they remain
analyst/KB-sourced. Plan 2 must not assume the bundle carries them.

cite-or-drop, zero analyst-prompt change). `fact_for` is the accessor. NOT wired this plan.
