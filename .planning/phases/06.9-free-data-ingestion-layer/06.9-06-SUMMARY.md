# Phase 06.9 Plan 06: prices.py Cascade + Cross-check Summary

Ranked multi-source price cascade with 0.5%-tolerance cross-check, ranked fall-through, structured divergence logging, and a hard no-imputation invariant — the redundant, self-verifying price substrate the whole backtest reads.

## What was built

`PRICE_PROVIDERS = [_av_weekly, _tiingo_eod, _yf_weekly, _nasdaq_daily]` (Stooq excluded/disabled) and `get_weekly_bars(ticker, start, end, *, providers=PRICE_PROVIDERS, tol_pct=0.5)` in `providers/prices.py`:

- **Ranked cascade + key-absent skip:** iterates providers highest-grade first (keyed GREEN Alpha Vantage/Tiingo, then always-on YELLOW yfinance/Nasdaq). Any source returning `[]` (no key, degrade, or miss) is simply skipped — no key required for the zero-config default (yfinance + Nasdaq).
- **Same-week (Friday-anchored) comparison only:** bars are indexed by the shared `week_end` (Plan 02 `friday_week_end`), so cross-check compares only the same real calendar week — a mis-anchored week can never falsely "agree" (`test_compare_by_aligned_week_end`).
- **Cross-check agree:** for a week_end in ≥2 sources, closes within 0.5% (`abs(a-b)/a`) → high-confidence, `agreeing_sources` = the agreeing set, `source`/`source_grade` = the highest-grade source's bar (kept as-is).
- **Cross-check diverge:** any source beyond tolerance → a structured `logger.warning` (ticker, week_end, per-source closes dict, max delta %), the highest-grade source's bar is kept, `agreeing_sources` narrows to just the sources that agreed with it (single → unconfirmed). Never averaged into a fabricated middle.
- **Never impute:** a week no available source carries is ABSENT from the output — no interpolation/ffill/fillna/impute. Acceptance grep is clean.

Each returned bar carries `source`, `source_grade`, `agreeing_sources` (a set) for `upsert_bars(..., source_grade=, agreeing_sources=)`.
