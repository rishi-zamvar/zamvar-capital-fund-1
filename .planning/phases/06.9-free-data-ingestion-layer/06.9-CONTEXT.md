<decisions>
## Implementation Decisions (LOCKED — from free-data-sources.md + operator)

### 1. Providers built per research, uniform interface, provenance on every datum
Each source becomes a provider behind the existing `providers/base.py` interface, and EVERY datum carries provenance (source_url, fetch_ts, source_grade) — consistent with the KB cite-or-drop invariant. Sources + roles (from research):
- **yfinance** — PRIMARY historical prices (weekly/daily bars). FMP 401s on historicals (confirmed) → yfinance replaces it for price history. ToS YELLOW-RED (tolerated personal use; non-authoritative) — treat as such.
- **CBOE delayed-quotes JSON** (`cdn.cboe.com/.../options/{TICKER}.json`) — options/IV/expected-move (the implied-move seam). No auth, 15-min delayed, ToS YELLOW.
- **FINRA Query API** — short interest (bi-monthly; store staleness honestly).
- **SEC EDGAR** — filings (S-1/S-3 offerings, 8-K, ownership).
- **Federal Register API + RTTNews** — PDUFA/AdCom dates (fills the empty pdufa_curated.csv; RTTNews scrape = YELLOW, Federal Register = GREEN documented API).
- **Nasdaq earnings + CT.gov v2** (CT.gov provider EXISTS) — earnings + trial readouts.

### 2. Scraper discipline (research + PROJECT.md)
Rate-limited; cached at >=5-min TTL (latency is fine — week-hold horizon); ToS posture documented per source (GREEN documented-API / YELLOW tolerated-scrape / RED avoid); graceful-degrade when a source is down or a name is illiquid — NEVER fabricate (mark UNVERIFIED/missing, degrade to the in-house fallback). Build-our-own (the shared repo was do-not-fork: no license, stale).

### 3. Wire the mocked seams to real providers — ZERO downstream contract change
The seams built in 6.5 (price_bar/bars_asof), 6.8 (company_card, implied_move source seam), 7 (backtest event set / fill) already exist behind interfaces. This phase wires them to the real providers behind the SAME signatures — no change to run_weekly/thesis_scan/company_scan/backtest contracts. Offline tests keep the mocks; a thin LIVE-mode path uses the real providers (network, cached).

### 4. Historical ingestion path
A path that populates price_bar + catalyst + company_card stores for the seed universe over ~1-2yr, point-in-time + survivorship-aware (keep delisted names' history). Idempotent + cached (re-runnable without re-hitting sources).

### 5. LIVE SHAKEDOWN = the phase verification (operator directive)
Ingest the REAL seed universe (data/seed_universe.csv, curated from research), then run Layer-A backtest + thesis_scan on the ingested real data END-TO-END. Log EVERY edge case / divergence-from-synthetic (illiquid names, missing bars, stale sources, delisting, ticker-symbol mismatches, timezone/holiday gaps, rate-limit hits). This is the real-data stress test of every system built so far. Triage: fix money-critical breaks now; log the rest.

### 6. Reuse + discipline
Reuse `providers/base.py` interface + the clinicaltrials/fmp provider pattern, `store.py` (upsert_bars/bars_asof, write_card/card_asof, catalyst write-path), the calendar/verify two-source gate, the backtest engine (7), thesis_scan (6.5). NEW: the per-source providers + a scraper/cache base + the historical ingestion path + a LIVE-mode seam toggle. Full TDD for the provider logic (mock HTTP — tests stay offline); the LIVE shakedown is a separate, explicitly-network step (not in the offline pytest suite — a script/CLI + a documented run). `.venv/bin/python -m pytest` (bare python NOT on PATH). Graphify graph-first.
</decisions>
