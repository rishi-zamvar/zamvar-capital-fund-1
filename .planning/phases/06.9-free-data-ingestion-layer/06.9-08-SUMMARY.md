## Deviations from Plan

### Auto-fixed Issues (money-critical, fixed in-place with tests — per the plan's triage directive)

**1. [Rule 1 - Bug] Null-close price bars crashed ingest**
- **Found during:** the live run (PHVS). yfinance returned `close=None` for every week while nasdaq had real closes. The cascade picked the highest-ranked available source (yfinance) as the cross-check reference and emitted a bar with `close=None` → `sqlite3.IntegrityError: NOT NULL constraint failed: price_bar.close`.
- **Fix:** root-cause guard in `prices.get_weekly_bars` where all callers route through — a bar without a close is a DEGRADE, dropped before ranking/cross-check. Also removes a latent None-arithmetic `TypeError` in the divergence delta and stops null-vs-real being logged as a spurious divergence.
- **Files:** `src/catalyst_trader/providers/prices.py`, `tests/test_price_cascade.py` (2 regression tests).
- **Committed in:** `9a79ddb`

**2. [Rule 1/2 - Bug + Missing] nasdaq ETF asset-class miss killed the sector reference**
- **Found during:** the live run. XBI and LABD (both ETFs) ingested **0 bars** — `_nasdaq_daily` hardcoded `assetclass=stocks`, so ETFs return no rows; with yfinance also null this run, the two ETFs had no source at all. **XBI is the sector-beta reference every `classify_drop`/`thesis_scan` needs**, so its absence silently killed the entire statistical sleeve (thesis_scan returned 0 rows; backtest ran defensive-only).
- **Fix:** `_nasdaq_daily` falls through to `assetclass=etf` when the stocks query returns no rows. Restored XBI+LABD → coverage 90.5% → **100%**, thesis_scan 0 rows → **21 rows** with real beta.
- **Files:** `src/catalyst_trader/providers/prices.py`, `tests/test_providers_prices.py` (fallthrough + degrade tests).
- **Committed in:** `3abc335`
