# Phase 06.9 Plan 01: Network Foundation Summary

One shared `providers/_http.py` base (`get_json` / `get_text`) enforces the INGEST-02 discipline — a >=5-min TTL dict cache, per-host sequential rate-limit, `httpx.HTTPTransport(retries=2)`, per-endpoint User-Agent (browser for YELLOW hosts, SEC declared-UA-with-contact-email from settings), and a degrade-to-None-never-raise-never-fabricate envelope — that every Wave-2 httpx provider will reuse; plus the 3 env-first settings keys the price cascade + SEC provider depend on and a raw-text conftest fixture loader for the RTTNews HTML fixture.

## What was built

- **`config.settings`** gained `sec_user_agent`, `alpha_vantage_api_key`, `tiingo_api_key` — all env-first (`.env`), all optional (default `None`) so the price cascade degrades to the always-on yfinance+Nasdaq pair when the GREEN keys are absent, and SEC calls fail loudly only when their UA is missing.
- **`tests/conftest.py::load_text_fixture`** — a raw-text sibling to `load_fixture` (`.read_text()`, no `json.loads`) for the RTTNews HTML fixture (Plan 05).
- **`providers/_http.py`** — `get_json(source, url, *, params, ua, ttl_s=300, host_key)` and `get_text(...)`:
  - module-level `(kind, source, url, sorted-params)` cache storing `(value, expiry)`; a repeat call inside the TTL returns the cached value with no network hit.
  - per-host rate-limit (`<=1 req/sec` + small jitter), reusing the ctgov spacing precedent.
  - `httpx.HTTPTransport(retries=2)` — the project-wide transport.
  - UA: `ua="browser"` -> browser UA string; `ua="sec"` -> `settings.sec_user_agent` (raises a clear `RuntimeError` config error if unset).
  - degrade on `HTTPStatusError`/`TimeoutException`/`TransportError`/JSON-decode -> `None`, logged, never raised, never fabricated; degraded `None` is not cached.
  - `_clear_cache()` test helper for isolation.
- **`tests/test_providers_http.py`** — 9 offline (pytest-httpx) tests: cache-within-TTL (exactly one wire hit for two calls), 403/timeout/bad-JSON -> None, SEC UA from settings, SEC UA unset -> config error, browser UA default, `get_text` raw string + degrade.

## Deviations from Plan

None of substance. One in-scope simplification: rather than add a new config field for HTTP spacing (Task 1 scoped settings to the 3 required keys), a module constant `_MIN_SPACING_S = 1.0` enforces `<=1 req/sec` — matching the plan's "config-driven spacing like ctgov_request_spacing_s is the precedent" intent without widening the settings surface.
