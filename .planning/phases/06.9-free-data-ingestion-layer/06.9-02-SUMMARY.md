# Phase 06.9 Plan 02: Store + Price Foundation Summary

Migration 007 adds two optional columnar cross-check-provenance columns (`source_grade`, `agreeing_sources`) to `price_bar`, `upsert_bars` gains two backward-compatible optional kwargs that write them on both INSERT and UPDATE, and `providers/_weekly.py` supplies the shared Friday `week_end` anchor + pure-Python daily->weekly resampler that makes every price source compare the same real week.

## What Was Built

### Task 1 — Migration 007 + upsert_bars provenance kwargs
- `007_price_bar_provenance.sql`: two `ALTER TABLE price_bar ADD COLUMN` statements (`source_grade TEXT`, `agreeing_sources TEXT`). Auto-applies via `db.migrate` (NNN > schema_version). No other columns.
- `upsert_bars(conn, ticker, bars, *, delisted=False, source="fixture", source_grade=None, agreeing_sources=None)`: two OPTIONAL kwargs default None. Both the INSERT and UPDATE SQL write the two new columns. Natural key `(ticker, week_end)`, idempotency, atomic commit/rollback — UNCHANGED.

### Task 2 — providers/_weekly.py
- `friday_week_end(d) -> str`: accepts ISO string / `date` / `datetime`; returns that Mon..Sun week's Friday ISO via ordinal shift `(4 - weekday())`. A Monday-indexed weekly bar (yfinance `1wk`) and any weekday of the same real week all map to the identical Friday.
- `resample_daily_to_weekly(daily_bars) -> list[dict]`: buckets daily OHLCV dicts by Friday `week_end` — open=first, high=max, low=min, close=last, volume=sum. Total + deterministic (empty->empty; holiday-shortened week still yields one Friday-keyed bar). Pure Python (`datetime` + `itertools.groupby`), no pandas.
