# Phase 06.9 Plan 03: Price Sources Summary

Four RAW/unadjusted, Friday-anchored per-source price fetchers behind a uniform `fetch_weekly_bars`-shaped signature: always-on `_yf_weekly` (yfinance `1wk`, `auto_adjust=False`, raw `Close`) + `_nasdaq_daily` ($-string OHLCV resampled), keyed `_av_weekly` (Alpha Vantage `TIME_SERIES_WEEKLY`, non-adjusted) + `_tiingo_eod` (raw `close`, not `adjClose`), plus a registered-but-disabled `_stooq`. All degrade to `[]`, never raise, never impute.

## What was built

- **`src/catalyst_trader/providers/prices.py`** — the five source functions. Reuses `_http.get_json` (cache/rate-limit/retry/UA/degrade) for the JSON sources and `_weekly.friday_week_end` / `resample_daily_to_weekly` for the anchor. A tiny `_f()` parses `$`-prefixed / comma / string / numeric prices to float. Zero new dependencies.
- **`tests/test_providers_prices.py`** — 11 offline tests. yfinance via an injected fake DataFrame (Monday index, `Adj Close` deliberately ≠ raw `Close`); JSON sources via pytest-httpx.
- **3 fixtures** — `nasdaq_hist.json` ($-strings spanning two Friday weeks), `av_weekly.json` (includes `5. adjusted close` ≠ `4. close`), `tiingo_eod.json` (`close` ≠ `adjClose`).

## RAW-price traps — tested per source

- **yfinance:** `test_yf_called_with_auto_adjust_false` asserts the downloader spy received `auto_adjust=False` + `interval="1wk"`; `test_yf_parses_raw_bars` asserts the stored close is the raw `Close` (10.50/11.40), not `Adj Close` (8.20/9.00).
- **Alpha Vantage:** `test_av_parses_raw_weekly` asserts close = `4. close` not `5. adjusted close`, and that the request URL contains `TIME_SERIES_WEEKLY` and NOT `_ADJUSTED`.
- **Tiingo:** `test_tiingo_reads_close_not_adjclose` uses a fixture where `close != adjClose` and asserts the weekly close is the raw close.

## Friday anchor — every source

yfinance Monday index → Friday via `friday_week_end`; AV native-weekly re-anchored to Friday; Nasdaq/Tiingo daily → `resample_daily_to_weekly`. Each source's test asserts `week_end == ["2026-08-07","2026-08-14"]`.

## Keyed sources degrade cleanly

`test_av_no_key_returns_empty` / `test_tiingo_no_key_returns_empty` — with the key monkeypatched to `None`, both return `[]` with no network call, so the zero-config default is the always-on yfinance+Nasdaq pair. `_stooq` returns `[]` (disabled).

None — plan executed exactly as written.
