    - resolve(conn, "kb:<id>") returns the EvidenceSource attrs dict (via kb.get_node) or None

    - resolve(conn, "tool:name#hash") returns a marker dict {"kind":"tool", ...} — tool refs

    - quote_supported(source_attrs, claim_quote) -> True iff claim_quote is a substring of the
