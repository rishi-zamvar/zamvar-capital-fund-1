# Phase 06.10 Plan 02: FRED Macro/Rates/VIX Provider Summary

Added `providers/fred.py` — the FRED macro-regime provider that fills the previously zero-coverage macro gap: Treasury rates (DGS10/DGS2), the yield curve (T10Y2Y), the policy rate (FEDFUNDS), free VIX history (VIXCLS), and CPI (CPIAUCSL) — every datum green-provenanced, routed through the existing `_http.get_json` base (cache/rate-limit/retry/UA/degrade), env-first on a new optional `fred_api_key`, and degrading to skip (never raising, never blocking the pipeline) when the key is absent. No new pip dependency.

## What Was Built

- **`fred.fetch_series(series_id)`**: keyed GET to `https://api.stlouisfed.org/fred/series/observations` (`params={series_id, api_key, file_type:"json"}`) through `_http.get_json` → `{series_id, observations:[{date, value:float}], latest, provenance:{source_url, fetch_ts, grade:"green"}}`. FRED's `"."` missing-datum sentinel is dropped (never coerced to 0). `None` on `_http` degrade (403/timeout/bad-JSON) or absent key.
- **`fred.fetch_macro()`**: fetches each of `MACRO_SERIES = (DGS10, DGS2, T10Y2Y, FEDFUNDS, VIXCLS, CPIAUCSL)`, assembles `{series_id: series_dict}`; a degraded/absent series is simply omitted (never fabricated). `{}` when no key.
- **`config.Settings.fred_api_key: str | None = None`** (env `FRED_API_KEY`) — env-first, optional, defaults None so the absent-key degrade path is the natural default.
- **`tests/fixtures/fred_dgs10.json`** — mirrors the REAL FRED `series/observations` shape (top-level `realtime_start`/`units`/`count`/… plus the `observations` array) including one `{"value": "."}` missing-value row.

## Correctness Guards (money-adjacent — no fabricated macro)

- **`"."` never becomes 0.** The `_f()` coercer returns `None` for both `None` and the string `"."`; `fetch_series` skips any observation whose value is `None`. `test_fred_drops_missing_dot_values` asserts `0`/`0.0` are absent from parsed values and the row count drops 4→3. Cite-or-drop: a holiday/no-print rate is dropped, not invented.
- **Degrade-to-skip without a key.** `fetch_series` returns `None` (logged once) and `fetch_macro` returns `{}` *before* any network call when `fred_api_key` is falsy — macro is context, not a gate, so a missing key just means no macro that cycle. `test_fred_no_key_degrades_to_skip` requests NO `httpx_mock`, so any attempted call would fail the test; it passes.
- **Degrade-not-raise on HTTP failure.** 403/timeout/bad-JSON flow through `_http`'s existing `_DEGRADE` handling → `None` per series; the bundle omits it. `test_fred_403_degrades` + `test_fred_macro_degraded_series_absent` (all-degraded → `{}`) confirm.
- **Green provenance on every datum.** `source_url` startswith `https://api.stlouisfed.org`, `fetch_ts` = UTC ISO now, `grade="green"`.
- **`_http` reuse, no bespoke client.** `fred.py` imports only `get_json` — no `import httpx`, no requirements/pyproject change (PIPE-04, zero new deps).

## Deviations from Plan

- **Found during:** Task 1 (first GREEN run)

- **Files modified:** tests/test_providers_fred.py
