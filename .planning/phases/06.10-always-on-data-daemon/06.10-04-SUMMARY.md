# Phase 06.10 Plan 04: N-source Median Cross-check + Split/Bad-tick/Stale Detectors Summary

Upgraded `get_weekly_bars` from 2-source pairwise to N-source median triangulation (robust to one bad source when >=3 report, even when the outlier is the highest-grade source), with an even-N no-consensus degrade-to-unconfirmed path, plus pure log-only split/bad-tick/stale detectors — never imputing, same migration-007 schema.

## What was built

**Task 1 — N-source median cross-check (`68c4d6b`)**
- For `week_end` with >=3 sources: `statistics.median` of the closes is a SELECTION probe; the in-tolerance set = sources within `tol_pct` of it; the highest-grade in-tolerance source's REAL bar is kept; `agreeing_sources` = that set. An outlier — even the highest-grade one — falls out of the set and is logged/excluded, never averaged in.
- **Even-N no-consensus split:** when the median lands between clusters (2-2) and the in-tolerance set is empty, it degrades to the highest-grade source's bar, `agreeing_sources = {that one}`, logged unconfirmed — never no-bar, never a crash, never the between-clusters median value.
- The <=2-source pairwise path and 1-source path are byte-for-byte the shipped 6.9 behaviour (regression guards green).

**Task 2 — quality detectors (`057a32a`)**
- `flag_split_candidates`: ~2x/~0.5x adjacent-week raw-close jump with no corroborating volume spike → candidate corporate action, flagged + returned, RAW closes NEVER mutated.
- `drop_bad_ticks`: single reverting >N-sigma spike (robust median + population stdev window) dropped, adjacent bars intact.
- `is_stale(fetch_ts, cadence_s)`: age > 2x cadence → True (the daemon/health signal for Plans 06/07).

## Correctness confirmations (money-adjacent)

- **Never impute — grep clean:** `grep -nE "interpolat|fillna|impute|ffill|mean|average" prices.py` returns nothing. The median is a selection probe only; every emitted close is a real source bar.
- **Even-N split degrades to unconfirmed:** `test_even_split_degrades_to_unconfirmed` green — a real highest-grade bar is emitted, `agreeing_sources = {that one}`, divergence logged, the between-clusters median (11.005) is never emitted.
- **Same-week comparison:** comparison keyed on the Friday-anchored `week_end`; `friday_week_end` alignment untouched.
- **<=2-source regression preserved:** `test_two_source_pairwise_unchanged` + `test_single_source_unconfirmed` + all shipped 6.9 tests green; `agreeing_sources` stays a set (ingest comma-joins it — contract intact); reused migration-007 columns, no new schema.
