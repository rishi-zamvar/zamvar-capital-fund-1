# Phase 07.7 Plan 02: Field Param Group in the Fitted-Params Seam Summary

Added a refit-able `field` param group (min_methods, trim_frac, dispersion_wide, move_discrepancy_tol + a structural-reliability method-weight table) to the ONE KB fitted-params seam — served by `load_params` on both the cold-start default and the cited-CSV-seeded path, deliberately decoupled from `diligence.DILIGENCE_PARAMS`.

## What was built

- **`kb.BOOTSTRAP_DEFAULT["field"]`** — cold-start defaults for the seven-weight table (`analog_cold` 0.5, `analog_warm` 1.0, `implied_liquid` 1.0, `base_rate_thin` 0.5, `base_rate_ample` 1.0, `rnpv_scenario` 1.0, `analyst_pt` 0.75) plus scalars `min_methods=2`, `trim_frac=0.0`, `dispersion_wide=0.5`, `move_discrepancy_tol=0.35`. All labeled uncalibrated for Phase-9 refit.
- **`data/fitted_params_bootstrap.csv`** — five new columns (`min_methods, trim_frac, dispersion_wide, move_discrepancy_tol, field_weights_json`) on all four catalyst rows, each keeping its existing evidence URL/snippet; `fit_source` annotated "field knobs uncalibrated — refit Phase 9".
- **`kb.seed_fitted_params`** — per-row `strategy` dict now carries a `field` block parsed by direct subscript (`int`/`float`/`json.loads`), so a missing column raises just like `evidence_url`.
