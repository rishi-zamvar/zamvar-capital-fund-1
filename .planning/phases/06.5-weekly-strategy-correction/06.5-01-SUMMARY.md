# Phase 06.5 Plan 01: Weekly Price-Bars Store + Weekly Params Summary

Point-in-time, survivorship-free weekly OHLCV price-bars store (`price_bar` table + `store.upsert_bars`/`store.bars_asof`) and the `"weekly"` threshold group in `kb.BOOTSTRAP_DEFAULT` — the GATING data + config substrate every Wave-2 weekly tool reads from, all tested offline against deterministic synthetic series.

## What Was Built

- **Task 1 — `price_bar` migration + `upsert_bars`:** `migrations/005_price_bars.sql` (auto-applied by `db.migrate`) defines the `price_bar` table (OHLCV, `delisted` flag, `source`, `UNIQUE(ticker, week_end)`) plus `idx_price_bar_ticker_week`. `store.upsert_bars` is atomic and idempotent on `(ticker, week_end)` (existing-row lookup → UPDATE else INSERT, mirroring `insert_catalyst`). XBI and delisted names round-trip like any ticker (survivorship-free).
- **Task 2 — `bars_asof` point-in-time read:** `SELECT ... WHERE ticker=? AND week_end <= ? ORDER BY week_end`. The `week_end <= as_of` guard is the money-critical no-look-ahead invariant, mirroring `universe.build.universe_as_of`'s no-future-cohort rule. Optional `lookback_weeks` slices the most recent N. Delisted history retained. Deterministic seeded-rng synthetic series (`_series` in the test) is the reproducible fixture Wave-2 base-rate tests will rely on.
- **Task 3 — `"weekly"` params group:** added to `kb.BOOTSTRAP_DEFAULT` with all 15 documented thresholds (including `statistical_sleeve_cap: 0.5`, research §4.5 knob #4). `load_params(conn, "weekly")` returns a deep-copy; a missing weekly key raises `KeyError` (no literal fallback hides in tool bodies). The catalyst-shaped `fitted_params_bootstrap.csv` was intentionally left untouched.

## Verification

- `tests/test_price_store.py` — 9 tests (round-trip, idempotent re-upsert, XBI, delisted, look-ahead gate, between-weeks exclusion, lookback, deterministic synthetic series).
- `tests/test_kb_params.py` — 4 new tests (every weekly key present, sleeve cap, missing-key raises, deep-copy) + 12 existing still green.

## Deviations from Plan

Minor (within Rule 3 — blocking-issue avoidance): Task 1's readback tests use a small raw-SELECT helper (`_readback`) instead of `bars_asof`, so Task 1 is self-contained and its RED/GREEN cycle does not depend on Task 2's deliverable. `bars_asof` is exercised by Task 2's tests. No behavior change to shipped code.

Otherwise: plan executed exactly as written. Synthetic fixtures implemented as the plan's explicitly-offered in-test seeded-rng generator rather than `tests/fixtures/` JSON files.
