# Phase 06.5 Plan 02: Weekly Sizing Rework — Target-Within-Survival-Cap + No Zero-Trade Weeks Summary

The money-critical rework of shipped Phase-5 sizing: `size_for_survival` now SERVES the ~1%/week target WITHIN the risk-of-ruin survival ceiling via `chosen = clamp(target_return/expected_move, FLOOR, survival_cap)` (the cap is the clamp's upper bound, so it is structurally un-crossable), and `select_book` deploys an injected defensive book instead of an empty one when nothing clears the bar — both changes INVERT a test-enforced Phase-5 invariant while keeping the exact Phase-5 behavior reachable through defaults (`target_return=None`, `defensive_book=None`).

## What Was Built

- **Task 1 — `size_for_survival` target-within-cap clamp + `assess` threading (PORT-03 amended / WEEK-04):** Added keyword-only `target_return`/`expected_move`. The existing downward risk-of-ruin sweep is kept byte-for-byte and captured as the local `survival_cap` (the hard ceiling). With `target_return=None` the chosen size collapses to `survival_cap` (exact Phase-5 behavior); otherwise `target_implied = target_return/expected_move` (guarded `expected_move>0`, else FLOOR) and `chosen = min(max(target_implied, FLOOR), survival_cap)`. The risk-of-ruin snapshot is recomputed at the chosen size so `ruin_at_size` reflects what we actually sized to. Both `target_return`/`expected_move` are added to the `inputs` dict (QUANT-03 reproducibility). BOTH docstrings (module + function) were rewritten from the old "NO return-target parameter / structurally decoupled from 1%" invariant to the new target-within-cap behavior. `assess` gained keyword-only `target_return`/`expected_move` (default None = byte-for-byte) threaded into the `size_for_survival` call.
- **Task 2 — `select_book` defensive-book fallback (WEEK-03, no zero-trade weeks):** Added keyword-only `defensive_book`. The greedy core is untouched; after it, if `promoted` is empty AND `defensive_book is not None`, `select_book` returns `(list(defensive_book), Σ size·move)`. With `defensive_book=None` (default) the empty/zero-trade catalyst path is preserved byte-for-byte.
