<decisions>
## Implementation Decisions (LOCKED — operator correction 2026-08-15 + research)

### 1. Sizing amendment (amends PORT-03; reworks shipped Phase-5 code)
Sizing is a function of BOTH the ~1%/week target AND survivability: `size = clamp(target_implied_size, floor, survival_cap)`. The TARGET drives the size; the risk-of-ruin `survival_cap` is a HARD CEILING the size can NEVER cross. Survival is the binding constraint when they conflict. Reworks `desk/risk.py::size_for_survival` (currently has NO target param) + how `desk/portfolio.py::select_book` aggregates — but the risk-of-ruin cap stays intact and test-enforced, and a NO-REGRESSION test proves the cap is never exceeded. This SUPERSEDES the old "1% is never a sizing input / survival-only" invariant (which was test-enforced in Phase 5 — that test gets inverted, not deleted, with a comment pointing here).

### 2. NO zero-trade weeks (supersedes Phase-5 "zero-trade allowed")
Every week produces a book. A weak-signal week deploys SMALLER (survival cap / more cash), never zero. When NO thesis cell clears the tradeability bar, the week is a DEFENSIVE book (cash-like anchors: SGOV/BIL + tiny XBI) with dossier language stating exactly that — never a forced failing trade. The old zero-trade-valid path is inverted with a test.

### 3. Universe-wide weekly thesis engine (WEEK-02) — MEASURED, cite-or-drop
A thesis on EVERY universe name every week, not only catalyst names. Types: (a) catalyst (reuse Workflow-1), (b) mean-reversion, (c) continuation/momentum. Each edge is a MEASURED historical base rate, never a hunch. Research decisive finding (Savor 2012, verified): info-driven moves DRIFT, no-info moves REVERSE → the drop-classifier (idio vs sector vs catalyst; info vs no-info, reusing `correlation_beta`) is what makes the thesis honest (a busted trial doesn't bounce). Honest measured ceiling (our own 18-biotech data): −5/−10% drops bounce ~54–55% vs 51.3% base (~+1% edge); −15% weeks = falling-knife HARD VETO; up-week continuation ~coin-flip unconditionally. Tradeability bar: edge ≥2pts AND n≥30 AND mean >2× cost AND CI>0 — expect only 2–4 cells to survive; beta-binomial shrinkage (mirror the estimator's `uncertainty_widened` seam) when n thin.

### 4. Weekly cadence (WEEK-01/05)
Weekly runner: Fri-close deterministic `thesis_scan` on ALL names (a "no measured edge" row IS the read) → weekend desk pass on the SHORTLIST only (reuse the analyst desk) → `select_book` (unchanged aggregation) → one-week hold → hard exit → rebuild. Weekly performance recorded vs the 1% goal, feeding the LEARN loop (Phase 10). Measurement trap: the base-rate window MUST equal the execution window.

### 5. Reuse discipline
NEW surface (per research): ONE module `quant/weekly.py` (3 deterministic tools: reversal base-rate, continuation base-rate, drop-classifier) returning frozen ToolResult; a weekly runner/orchestrator entry; the sizing-amendment edit + select_book edit. REUSE: `risk_of_ruin`/`fractional_kelly`, `correlation_beta`, `base_rate`, `kb.analog_query`, the estimator shrinkage pattern, the analyst desk, `select_book`, the contracts. Statistical (non-catalyst) legs are SINGLE-LEG (hedge logic stays catalyst-only; reuse the Phase-5 size-tiny fallback). Agents interpret; deterministic tools compute. Full TDD, offline (`.venv/bin/python -m pytest`, bare python NOT on PATH). Graphify graph-first (freshly re-indexed, 2215 nodes).
