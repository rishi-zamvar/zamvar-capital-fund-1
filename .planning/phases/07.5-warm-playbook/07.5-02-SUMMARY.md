# Phase 07.5 Plan 02: No-Look-Ahead Leak-Gate Summary

The load-bearing no-look-ahead retrieval gate: a `knowable_asof <= as_of` clause in
`kb._structural_filter`/`analog_query` (additive, `as_of=None` default = today's behavior), threaded
through `desk/builder.py::build` and the `desk/tools.py` analog tool, plus a cohort-aware
`conditional_filters` so tightening type+indication never starves the KNN below `min_analogs`.

## What was built

- **`kb._structural_filter(conn, filters, as_of=None)`** — when `as_of` is set, appends
  `AND json_extract(attrs_json,'$.knowable_asof') <= ?`. ISO dates compare lexicographically; a node
  missing `knowable_asof` yields `NULL <= date` = NULL (falsy) → excluded (fail-safe).
- **`kb.analog_query(..., as_of=None)`** — passes `as_of` into the structural filter. Because
  `knowable_asof` is the T+2 date, one gate covers both catalyst existence and its realized move.
- **`kb.conditional_filters(conn, ctype, indication=None, min_analogs=5)`** — returns
  `{"type": ctype}`, adding `indication` only when the type+indication cohort count ≥ `min_analogs`.
- **Seam threaded** — `builder.build(..., as_of=None)` forwards into `analog_query`; the desk
  `_analog_query` `@tool` schema gains an `as_of` key (`args.get("as_of")`→None) and forwards it.
  Both call sites record `as_of` in their evidence ref so the citation is honest.

## The mandatory no-look-ahead test

`tests/test_playbook_leakgate.py` (8 tests):
- Two catalysts (`knowable_asof` 2024-01-15 vs 2025-06-15), same embed text (both KNN-close):
  - `as_of="2024-06-01"` → ONLY the earlier node **and its outcome** (`{"move": +0.2}`).
  - `as_of=None` → both (backward compatible).
  - `as_of="2026-01-01"` → both (gate is `<=`).
- Node missing `knowable_asof` → EXCLUDED under `as_of="2026-01-01"`, surfaces under `as_of=None`.
- `conditional_filters`: thin cohort (<5) drops indication; ample cohort (≥5) keeps it; no indication → type-only.
