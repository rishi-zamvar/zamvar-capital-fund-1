# Quick 260818-n98: Tier-1 Data-Integrity — De-conflate Labels Summary

Three offline, TDD, in-memory-verifiable data-integrity fixes for the warm playbook: honest
outcome fields (market reaction vs real result), zero-API signed-move verification, and cross-filer
EDGAR source pruning — plus a pb_agent `--own_cik` pin. **Tasks 1-3 (code) are done, committed, and
green. Task 4 (live application over the real ~470-node catalyst.db) is left for the orchestrator.**

## What Was Built (Tasks 1-3)

### Task 1 (FIX A) — De-conflate the outcome label  ·  commit `85f1efd`
- `schema.market_reaction(signed_move)` — pure, banded from the SIGNED move:
  `crashed` (<= -0.15) / `faded` (-0.15..-0.03) / `flat` (|m|<=0.03) / `popped` (0.03..0.15) /
  `surged` (>= 0.15) / `unknown` (None). Bands = `BIG_MOVE_BAND` / `INLINE_BAND`.
- `schema.clinical_regulatory_outcome(catalyst_type, what_happened, why_narrative)` — deterministic
  per-type keyword parse (pdufa: approved/crl/delayed; readout: hit/miss/mixed; earnings:
  beat/miss/inline; adcom: favorable/unfavorable), specific-phrase-wins ordering, `None` on no
  reliable match (the Task-4 LLM pass fills Nones).
- `schema.to_outcome_attrs` now emits both new keys; legacy `label` + SIGNED `move` unchanged.
- `extract._EARNINGS_INLINE_BAND` now = `schema.INLINE_BAND` (single source of truth, zero behavior change).
- `store.backfill_outcome_fields(conn, classifier_fn=None)` re-stamps the two keys onto EXISTING
  outcome nodes (content_sha idempotency does NOT auto-backfill). **Reads the catalyst type from
  `attrs["type"]`** (the top-level key `to_catalyst_attrs` writes), NOT `attrs.get("catalyst_type")`.
  The deterministic PDUFA-"approved" backfill test passes with **NO classifier** — it fails if the
  wrong key is read.

### Task 2 (FIX B) — Verify + correct signed moves from cached bars  ·  commit `ffa4f7e`
- `verify_moves.recompute_signed_move(bars, event_date, window=(-1,2))` — pure SIGNED recompute;
  `None` on month-precision (len!=10), guarded/missing window, or null/zero close (never imputed).
- `find_move_divergences(conn, bars_provider, *, tol=0.02)` — flags stored-vs-recompute gaps > tol
  via an **injectable** `bars_provider` (offline in tests, get_daily_bars-backed live). `None`
  recompute is never flagged.
- `correct_move(conn, catalyst_id, move_window, new_move)` — idempotent single-row UPDATE.

### Task 3 (FIX C) — Prune cross-filer sources + pb_agent --own_cik  ·  commit `12974a4`
- `extract.prune_cross_filer_sources(conn, catalyst_id, own_cik)` — reuses `cik_filter_exhibits`
  for the keep-set; deletes wrong-CIK EDGAR rows, dedupes exact-duplicate own-CIK urls (keep lowest
  id), leaves ct.gov / non-EDGAR untouched, returns dropped rows `[{id, source_url, reason}]`.
  `own_cik=None` is a no-op (no guess).
- `scripts/pb_agent.py` — added `--own_cik` threaded through `main(argv)` → `cmd_prompt`/`cmd_insert`
  → `build_bundle(own_cik=)`; `main(argv)` extracted so the passthrough is testable offline
  (monkeypatched `_conn` → no stray catalyst.db). Default (None) behavior unchanged.

**FIX B — verify + correct moves (zero paid API), write the diff artifact:**
```python
import sqlite3, json
from catalyst_trader.playbook.verify_moves import find_move_divergences, correct_move
from catalyst_trader.providers.prices import get_daily_bars, _yf_daily, _nasdaq_daily_bars
from datetime import date, timedelta
conn = sqlite3.connect("catalyst.db"); conn.row_factory = sqlite3.Row
def bars_provider(ticker, event_date):
    s=(date.fromisoformat(event_date)-timedelta(days=14)).isoformat()
    e=(date.fromisoformat(event_date)+timedelta(days=14)).isoformat()
    return get_daily_bars(ticker, s, e, providers=[_yf_daily,_nasdaq_daily_bars])
divs = find_move_divergences(conn, bars_provider, tol=0.02)
json.dump(divs, open(".planning/quick/260818-n98-tier-1-data-integrity-de-conflate-labels/move-divergences.json","w"), indent=2)
for d in divs: correct_move(conn, d["catalyst_id"], "(-1,2)", d["recomputed"])
print(f"corrected {len(divs)} divergent moves; suspects VERA/ZBIO/LYRA/QURE should appear")
```
