<objective>
Wire the stateless `desk/portfolio_builder.py::build_portfolio` engine into the weekly desk
assembly so the whole-book risk read runs AUTOMATICALLY. Today `build_portfolio` is only exposed
as an analyst MCP tool (`desk/tools.py::_build_portfolio`); it does NOT run when the desk assembles
the weekly book. This plan adds a pure adapter that maps the assembled book's promoted
`TradeProposal`s into the engine's `(positions, assumptions)` contract, calls the engine once after
the book is selected, and attaches the resulting `PortfolioOutcome` to each promoted dossier — so
the human and the PM/MD see whole-book exposure/concentration/correlation-vol/scenario+sector-shock
P&L/risk-of-ruin, not just per-candidate numbers.

Purpose: close the "risk read is per-candidate only" gap for the weekly book.
Output: `book_to_portfolio_inputs` adapter + one optional `PortfolioContext.portfolio_outcome`
field + a guarded attach pass in `run_portfolio`. Purely additive; the money path (select_book
sizing/selection) is untouched. The PortfolioOutcome is a RISK READ this phase — it does NOT
resize or alter selection (correlation-aware sizing is a future, separate decision).
</objective>

Per-name up/down/p_positive live on the RECONCILED proposal's ExitPlan, NOT as loose fields:

Statistical/defensive legs (built by portfolio.py::build_weekly_leg_dossier) have exit_plan=None;
their only move is proposal.expected_return_pct (a probabilistic mean, not an up-move).

```python
class TradeProposal(BaseModel):          # extra="forbid", MUTABLE (not frozen)
    target_long: str
    hedge: Hedge | None                  # Hedge has ticker, payoff_direction(+1/-1), instrument, ... — NO size_pct
    entry: float
    size_pct: float
    expected_return_pct: float           # blended net EV (statistical/defensive legs' only move)
    holds_through_catalyst: bool
    direction: Literal["positive","negative"]
    exit_plan: ExitPlan | None = None    # catalyst legs carry it; statistical/defensive legs = None
    hedge_profile: dict | None = None    # out-of-band corr facts (peers[].corr_full, xbi.full.{corr,beta})

class ExitPlan(BaseModel):               # frozen
    ev_flip: EvFlipGuard                 # .upside=up_move  .downside=down_move  .p=p_positive
    ...

class PortfolioContext(BaseModel):       # extra="forbid", MUTABLE — the BOOK-LEVEL risk container
    concentration: float                 # already book-level
    corr_to_open_positions: list[float]
    weekly_budget_remaining: float
    # >>> ADD: portfolio_outcome: dict | None = None   (mirror TradeProposal.hedge_profile optional-additive)

class StrategyDossier(BaseModel):        # extra="forbid", MUTABLE
    decision: Literal["promote","kill"]
    trade: TradeProposal
    portfolio_context: PortfolioContext
    ...
```

build_portfolio contract (portfolio_builder.py — DO NOT modify the engine):
  build_portfolio(positions: list[dict], assumptions: dict) -> PortfolioOutcome
  positions[i] = {"ticker": str, "side": "long"|"short", "size_pct": float, "hedge"?: {...}}
  assumptions = {
    <ticker>: {"expected_move": float, "down_move"?: float, "p_positive"?: float, "sigma"?: float},
    "corr_source": dict | callable(ticker)->profile|None | None,   # default in the MCP tool: lambda t: kb.hedge_profile(conn, t)
    "sector_shock": float,                                         # XBI stress magnitude (defaults 0.0 in engine)
  }
  Engine already DEFAULTS: missing down_move -> |expected_move|; missing p_positive -> 0.5 (PARAMS).
  Engine RAISES (subscript) if a position ticker has no assumptions[ticker]["expected_move"].
  PortfolioOutcome.model_dump() keys: gross_exposure, net_exposure, concentration, max_weight,
    expected_return, portfolio_variance, portfolio_vol, covariance_detail, scenarios, risk,
    assumptions_echo. risk["risk_of_ruin"] is None when no scenario loses money, else a float.

kb.hedge_profile(conn, ticker) -> dict | None   (the tool default corr_source; run_portfolio has `conn`)
