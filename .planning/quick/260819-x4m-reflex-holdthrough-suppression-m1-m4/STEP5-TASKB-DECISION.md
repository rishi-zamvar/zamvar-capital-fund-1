# Step 5 — Task B go/no-go decision (evidence-based)

**Decision: DEFER the originally-scoped Task B (off-map agentic brain). Do NOT build it now.**
**A different, more valuable lever emerged — event-anchored EXIT TIMING — which must be validated on the FORWARD PAPER MONTH, never tuned on the in-sample 42 legs.**

## The original Task B was: off-map agentic escalation
Task A left a seam: when an intraweek outcome is "off-map" (no scenario-table branch covers it), escalate to a single reasoning agent (with reasoning-latency modeled). The go/no-go criterion set at the start of this run: **is the money leaking in the off-map path?**

### Evidence: NO.
- Pre-fix off_map: 1/48 (~2%), and even that was measured under the broken band (mislabeled tp/band exits).
- Post-fix off_map: **0/108 = 0.0%** on the real cache. Band-excess off_map is correctly suppressed for hold-through legs; no halt-rolls fired.
- The ~810pp the reflex was destroying was **entirely on-map** (tp/band/stop firing on hold-through legs), now fixed by M1.

Building the off-map reasoning agent now would be polishing a 0.0% rounding error. **Permanent defer** (until a forward month shows genuine off-map frequency).

## The real next lever (discovered by the Step-4 verifier): post-event EXIT TIMING
The residual daily-vs-weekly gap (daily +7.67% vs weekly +15.31% on the paired 42 legs) is **systematic and directional**, not noise. Per-leg tracing shows two disjoint capture windows:
- The **weekly** model exits at the hold-week **OPEN** — i.e. it books the immediate post-event **gap/pop** and gets out.
- The **daily** reflex now (post-M1) holds to the **time barrier** — riding *through* the post-event **fade**.
- Example RAPP: weekly exits ~38.42 (the pop); daily holds from there down to ~23.76.

So on these catalysts the edge was in **exiting at the event resolution (the gap), not holding to Friday.** This is the desk's own "execution AT the event" principle showing up in the data — and it is an exit-TIMING decision, which is the legitimate heir to "Task B":
- It could be **deterministic** (exit at/near the event-resolution bar — capture the pop, skip the fade), or
- **agentic** (reason at the event: is this a pop-and-fade to sell, or a sustained re-rating to hold?).

### Why NOT build it now
- The signal comes from **42 in-sample legs (7 real winners)** over the SAME history the playbook was built on. Tuning an exit-timing rule on this set is textbook curve-fitting — the exact trap the Step-3 vetter and this whole chain were disciplined to avoid.
- The correct proving ground is the **forward paper month** (CLAUDE.md paper-first; the CEO's stated real edge proof). Calibrate exit timing there, on events the system never trained on.

## Recommendation / next actions (for CEO, not autonomous)
1. **Ship the current fixed exit engine** (M1) into the paper month as-is: hold-through legs hold to the time barrier, honest gap-open/latency modeling, resting broker-side SL/TP for non-hold-through legs.
2. **Instrument the paper month to measure exit timing**: for each catalyst, log the event-resolution price, the gap-open, and the drift afterward — so we get an OUT-OF-SAMPLE read on "exit-at-event vs hold-to-barrier."
3. **Re-decide the exit-timing lever after the paper month** with real out-of-sample evidence. If off_map frequency shows up there too, the agentic brain re-enters scope with real data behind it.
