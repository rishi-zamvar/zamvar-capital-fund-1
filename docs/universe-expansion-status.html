The pivot

Screen on catalyst movement, not size

The old screen capped market cap and dropped prime names (BBIO, AXSM, PRAX). The new rule keeps a name only if its catalysts have historically moved the stock ≥10% (median) — the trait that actually makes a catalyst tradeable. Big or small, if the events move it, it's in.

This required computing every name's real past catalyst moves — which front-loads exactly the historical data the year-long walk-forward needs anyway.

Discover→ Backfill 5-yr catalysts→ Compute realized moves→ Screen by movement→ Rank & write cohort

What got built

Broader, safer discovery plan 05

Widened the SEC 8-K PDUFA search to 5 years (20 names/yr → 256 candidates) and added exact-match company→ticker resolution so real biotechs stop getting dropped — with a strict rule that any ambiguous name goes to a human review queue, never a guessed ticker.

Movement screen + history store plan 06

New database table for realized catalyst moves, a daily-price accessor, the T-1→T+2 move math (stamped with when it became knowable, so nothing peeks at the future), and the screen itself. The market-cap ceiling was removed entirely.

Options liquidity fix plan 04

Fixed how the option chain's at-the-money contract is picked. It now chooses a liquid, near-the-money monthly contract instead of whatever thin weekly quoted first — a fix that also sharpens the diligence desk and implied-move tools that share the same code.

Three gaps only live data revealed

Every plan passed its offline tests. Then running it on the real internet exposed three things fixtures never could — each found, diagnosed, and fixed on the spot.

Never discard fetched data

The trial-search feed hit a rate limit mid-way and threw away every page it had already fetched. Rerouted it through the archiving layer: every page is now saved to the raw data lake and a failure keeps what it already has. Your standing rule, applied.

Options were being read wrong

17 of 20 clearly-optionable names were being rejected as "not optionable" — the chain reader was grabbing a worthless far-out-of-the-money contract. That's the plan-04 fix above; it surfaced here, on live chains.

No historical prices for the moves

The screen's whole point — past moves — computed for only 1 of 779 catalysts: the daily-price sources couldn't reach back in time (one needs a paid key, one only serves recent data). Added yfinance daily as the reliable free multi-year source. Moves now compute; this was the last blocker.
