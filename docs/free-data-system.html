The Free Data System

How the desk gathers every number it trades on — for $0, forever — by running our own web-scraping pipeline across many redundant public sources, cross-checking them against each other, and refusing to fabricate anything it can't cite.

● $0 / month · redundant + cross-checked · accuracy over speed

◆ The whole system in one picture

Public sources → a disciplined fetch layer (cache, rate-limit, honest UA, graceful-degrade) → cross-check/triangulation → one point-in-time store with provenance on every datum → the desk reads the store. An always-on launchd daemon runs the whole loop on a schedule, repairs gaps, and reports its own health.

⚑ How the models flag a data problem

Accuracy-first means the pipeline is loud when something's wrong rather than quietly serving bad numbers. Four independent alarms, all surfaced in the monitor's data-health tab (and optionally a phone ping):

STALE
Age > 2× cadence. A datum's fetch_ts is older than twice its expected refresh (see table) → source marked degraded, the desk knows the number is old before it trades on it.
DIVERGE
Sources disagree. When ≥2 feeds return the same name-week and their closes differ beyond tolerance (0.5%), keep the highest-grade value, narrow agreeing_sources, and log the divergence — never average into a fabricated middle.
GAP
Coverage hole. Expected name-weeks (universe × weeks) vs. rows actually present → missing set enqueued for backfill; coverage-% drop is an alert.
DEAD
Source down. Consecutive-failure counter per source; after N failures it's marked dead and the cascade fails over to the next-ranked feed. The pipeline degrades, it never crashes.

⚙ What it requires  ·  What it outputs  ·  How it helps

Requires

  • Deps: httpx, yfinance, bs4/lxml, edgartools (the one new one) — all free/open
  • Keys (all optional): Alpha Vantage + Tiingo (upgrade prices to GREEN), FRED (macro). Absent → degrades gracefully to the always-on sources
  • SEC identity: a contact-email User-Agent (SEC rule) — env-first, never hardcoded
  • Runtime: macOS launchd + local disk. No cloud, no server, no paid tier

Outputs

  • The store: point-in-time price bars, verified catalysts, company cards, macro series — every row carrying source, timestamp, grade, and who-agreed
  • data_health.json: live coverage %, per-source health, staleness, gaps, divergences
  • Raw-snapshot lake: every fetched response kept on disk for audit + re-parse-without-refetch

How it helps

  • The desk always reads fresh, triangulated, point-in-time data — so a weekly portfolio, a backtest, and the scanner all run on the same trustworthy numbers
  • Cite-or-drop: nothing untraceable reaches a trade decision — the human gate sees provenance
  • No look-ahead: raw prices + week_end ≤ as_of guards mean the backtest can't cheat
  • $0 + redundant = no vendor lock-in, no bill, no single point of failure

✕ What we honestly cannot get for free

Being explicit about the ceiling matters more than pretending it isn't there. None of these blocks the current strategy — but each is a known limit the desk is designed around, not surprised by.

PAID
Vendor-cleaned event analytics (ORATS / Market Chameleon precomputed expected-move + historical intraday IV surfaces). We compute the expected move ourselves from the raw chain — same math — but vendor event-studies and intraday IV history are paid. Not needed: the enriching-input design uses the raw chain we already get.
EST
Authoritative float. Free float is an estimate everywhere — it's a vendor calculation. We take SEC shares-outstanding (exact) + yfinance float (estimate) and label it estimate-grade rather than pretend precision.
DELAY
Real-time quotes + tick data. Everything free is EOD or 15-min delayed; true real-time and tick-level data are paid. Deliberately fine — decisions are weekly-hold (latency irrelevant), and even the intra-week monitor only needs the 15-min-delayed feed to defend a position. Accuracy > latency by design.
THIN
Options on the thinnest names. No vendor fixes a zero-open-interest chain. The liquidity gate + in-house gap estimator is the answer (drop junk IV), not spend.
SCOPE
Broad-universe catalyst discovery + conference abstract→company mapping. Our 3-source PDUFA stack covers a curated ~20-name universe well; a market-wide screener or "who presents which abstract when" is a paid tracker / company-PR job. Out of scope now.
