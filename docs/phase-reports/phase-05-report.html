✓ What's done

  • The whole positioning workflow is assembled — run_portfolio takes the week's binary verdicts and runs each through: build → estimate → vet → risk committee → reconcile → select the book → PM promote/kill → a StrategyDossier. 7 plans across 4 waves.
  • The honest-hedge reality is built in, not papered over — the research proved clean idiosyncratic hedges are rare, so the default is a survival-sized single leg. A pair is used only when the risk agent re-validates, per-catalyst, that the peer actually rises when the target falls (un-netted worst-case cell + cointegration + catalyst-clean). A fake hedge is literally unrepresentable at the data boundary.
  • Sizing is for survival, never for the 1% target — the sizing function has no return-target parameter at all (enforced by a signature test), so it structurally cannot be talked into chasing a number. It sizes off the estimated down-move, not a generic guess.
  • Hold-vs-exit uses expected-log-growth, not raw expected value — a trade with a tempting positive average but a fat losing tail is correctly told to exit before the event. There's a pinned test proving exactly that case fires.
  • Every number is model-derived, and the "moat" hook is in place — no magic constants; the estimator/SL-TP thresholds are loaded parameters that will be re-fit from real outcomes later. Each estimate is vetted for its assumptions (are the analogs comparable? is the probability cited?) before it can become a position — and a rejected estimate blocks the trade.
  • Accountability like a real desk — the position memo + pre-mortem are authored separately from the PM who approves (author ≠ approver, test-enforced). Zero-trade weeks are a valid outcome.
  • 649 tests, entirely offline — up from 498 at phase start (+151). No live API call anywhere in the suite; all agent reasoning tested through one recorded-response seam.

Across three research passes, most idiosyncratic biotech binaries have no clean long-only hedge — a competitor usually moves with the target on a class win, not against it.
