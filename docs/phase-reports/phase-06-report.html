✓ What's done

  • The firewall is enforced by the type system, not by hoping — the diligence desk can only be handed {ticker, catalyst, pair}. Passing it any of Workflow 1/2's reasoning (the thesis, the verdict, the sizing) is a compile-time impossibility, proven by a field-disjointness test. That's the "provably never passed in" you asked for, made structural.
  • Eight independent diligence dimensions, each from raw sources — trial stats, regulatory precedent, financials/runway, ownership/flow, options-implied move, an independent hedge re-validation, liquidity, and historical analog — each producing a source-cited signal, reusing the existing tools (no re-implementation).
  • A synthesizer that's rigged to kill, and that the AI can't overrule — a single failing money-touching dimension forces NO-GO; a GO requires every money dimension to be present and data-backed. The verdict is computed deterministically; the language model writes only the narrative and cannot flip a NO-GO to a GO.
  • No hallucinated finding can produce a false GO — if a money dimension has no real underlying data, it can't quietly "pass"; the trade is forced to NO-GO. This was a bug the plan-check caught before any code shipped.
  • The independent hedge check re-validates the ACTUAL pair — not just whatever the database returns first — so "hedge valid" always refers to the hedge the portfolio actually proposed.
  • 689 tests, entirely offline — the whole second desk is tested through one recorded-response seam; zero live API calls.
