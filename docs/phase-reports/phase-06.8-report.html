Phase 6.8 — Weekly Company-Vetting Scanner

● VERIFIED · 22/22 must-haves · 7/7 invariants · 831 tests
2026-08-15 · SCAN-01…04 + WEEK-06 closed · goal: a cheap, refreshable weekly scan of every company — deterministic flaggers find who's worth a look, a Haiku analyst does a KB-armed once-over on those.

✓ What's done

  • Every company gets a weekly read — for pennies — a cheap deterministic layer refreshes a "company card" for all ~20 names and only wakes a Haiku analyst on the handful whose metrics genuinely changed week-over-week. A whole quiet week costs about 5 cents; a wild one about 21.
  • 13 deterministic flaggers, all from data we actually have — catalyst-window crossings, competitor-catalyst proximity, IV/expected-move shifts, short-interest moves, volatility regime, moving-average crosses, volume anomalies, runway drops, offering filings, and thesis-row transitions. Data we don't have (daily short interest, 13F) is marked future, not faked.
  • The signal is the CHANGE, not the level — a flag fires once on a real transition and then latches; it won't re-fire until the metric retreats past half the threshold (hysteresis). This is what makes the weekly refresh honest instead of noisy — and it's proven replayable across weeks by a two-week round-trip test.
  • The Haiku once-over is smart because it reads the memory — on a flagged name it queries the knowledge base for similar past situations + outcomes and the learned playbooks, then says what's worth exploring this week — cite-or-drop, and "no opportunity" is a first-class answer it's allowed to give.
  • It's a genuine replica, not a copy-paste — it reuses the diligence workflow's discipline (firewalled input, cite-or-drop) as ONE cheap Haiku pass, deliberately not the heavy 8-agent fan-out.
  • Routing was free — the MD router built last phase already accepts these flags, so this shipped with zero changes to the MD code. Opportunities land in the MD's queue; the MD decides whether to verify and act.
  • 831 tests, fully offline — +28 this phase; every threshold is a named parameter (no magic numbers), the whole thing runs on synthetic data with no live API.

★ What's going well

Plan-check caught a silent bug tests would never have. The scanner was saving the company card before updating its latch memory — so next week a flag could spuriously re-fire, quietly breaking the whole point of week-over-week comparison. No unit test would have failed. Caught at plan time, fixed with a two-week regression test. That's the sixth straight money phase the review round-trip has earned its cost.
