Phase 6.10 — Always-On Data Daemon

● COMPLETE · 7 plans / 4 waves · 1057 tests · the redundancy-proven milestone
2026-08-16 · PIPE-01…10 closed · goal: make the free data pipeline run constantly, self-heal, and prove multi-source redundancy on real data.

✓ What's done

  • The pipeline now runs itself. A launchd daemon executes a stateless run_cycle() on a schedule, backfills gaps, fails over dead sources, and writes its own health report — crash-recovery via launchd, resumability via idempotent UPSERTs. No servers, no queues, $0.
  • Multi-source redundancy is proven on real data — the headline result. The live run cross-checked 1088 of 1092 weekly bars against ≥2 independent sources; the 4 that didn't were real disagreements, flagged and logged, never averaged into a fake number.
  • Free fundamentals + float are in via edgartools (SEC-XBRL) — the #1 gap from the original research. Cash-runway for 15 names, filings for 19, and the old "no CIK" problem is gone (it resolves CIK internally).
  • Macro/regime coverage added — a FRED provider (rates, curve, VIX) fills what was previously zero coverage, for the desk's risk-regime context.
  • An N-source median cross-check (robust to one bad source in ≥3) plus split / bad-tick / stale detectors — accuracy is the lever, and it never imputes a missing bar.
  • Data-health is visible — per-source health, coverage %, staleness, gaps, and per-cycle divergences surface in the monitor with alerts on degradation.
