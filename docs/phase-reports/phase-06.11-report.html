Phase 6.11 — Our Own PDUFA Source

● COMPLETE · 4 plans / 3 waves · 1097 tests · the blocker-clearing phase
2026-08-16 · PDUFA-EDGAR-01…04 + RH-DATA-01/03 closed · goal: build our own free, authoritative PDUFA/AdCom catalyst source from SEC 8-K filings — and prove it live.

✓ What's done

  • We now mint our own PDUFA dates — free, keyless, authoritative. providers/pdufa_edgar.py discovers PDUFA/AdCom 8-Ks via SEC EDGAR full-text search (CIK-filtered to our universe, no HTML scraping), fetches the real EX-99.1 exhibit, and extracts the date with a deterministic regex — no LLM ever mints a date (cite-or-drop: only a date verbatim-adjacent to a keyword in a real linked filing).
  • A single SEC-EDGAR filing self-verifies → tradeable with zero change to the verify rule (SEC EDGAR was already whitelisted as an authoritative single source). The catalyst is point-in-time stamped from the 8-K's own filing_date — no look-ahead.
  • It runs on the daemon path automatically. Wired into ingest._fetch_catalysts + the provider registry, so PDUFA dates auto-populate every run_cycle — closing the exact wiring gap the earlier pdufa debug exposed.
  • Confidence gating with a human review queue. Clean single-date filings auto-emit as tradeable; multi-date / ambiguous / AdCom-only filings route to a #-commented review CSV for you to confirm — the ~10-min/week task, now auto-populated from real filings.
  • A read-only Robinhood data adapter (quotes / float / portfolio, degrade-to-None) landed as a bonus — pluggable, offline-tested, never sole-source, and gated off until you connect the MCP.
  • Proven LIVE on real SEC data (this closing plan) — see below.
