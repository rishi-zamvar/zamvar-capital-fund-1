What the deflated Sharpe of 0.32 means, plainly: if you pretend we only ever tried one version of the strategy, the +18% looks strong. But we effectively tried ~100 combinations of settings/names, and when you try that many, something looks good by chance. Corrected for that, confidence this is real skill is ~1-in-3 — not proven.
