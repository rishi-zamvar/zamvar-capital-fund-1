💊 The one decision money is actually about: PDUFA

No free authoritative forward-PDUFA API exists

Company PRs originate PDUFA dates; commercial trackers just aggregate them — so a subscription buys breadth + convenience, not authoritativeness. For our curated ~20 names, the free stack (RTTNews discovery + Federal Register AdCom + EDGAR PR confirmation) already reduces PDUFA to a ~10-min/week review. Recommendation: stay $0, curate PDUFA as a reviewed table, and buy a tracker only if you expand well past 20 names.

Honest pricing gap

I could not verify a single paid-PDUFA price — BPIQ, FDATracker, MarketBeat, and Benzinga all bot-wall automated fetching, and the research session's web-search budget was exhausted. Per our no-fabricated-numbers rule I won't print a number I can't source. The ~$30–100/mo figure is a historical band to size the decision, not a quote. Opening biopharmacatalyst.com/pro in a browser is a 2-minute check I'm structurally blocked from doing.
